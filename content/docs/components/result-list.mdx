# Result List (`Ux4gResultList`)

The UX4G Result List (and its companion alias `Ux4gResultRow`) provides an expandable list item component designed for government service portals, application tracking dashboards, search listings, and grievance monitoring systems.

### Key Capabilities

- **Expandable Accordion Behavior**: Smooth animated expansion (`AnimatedVisibility`) revealing structured 2-column (or custom) metadata details grids.
- **Status Tags & Pill Segments**: Integrates with `Ux4gTag` (e.g. Approved, Pending, Rejected) and `Ux4gUnifiedPillTag` metadata segments.
- **Action Buttons**: Built-in outline CTA button with optional leading icons (e.g., "View Details", "Download", "Track Status").
- **Customizable Layout**: Configurable detail columns, custom trailing icons, title badges, and bottom dividers.

Import from `com.ux4g.designsystemv1.components.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

### 1. Application Tracking Card

```kotlin title="ApplicationTrackingCard.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.*
import com.ux4g.designsystemv1.foundation.Ux4gColors

@Composable
fun ApplicationTrackingExample() {
    Ux4gCard(
        modifier = Modifier.fillMaxWidth(),
        cornerRadius = 12.dp,
        borderColor = Ux4gColors.neutral900.copy(alpha = 0.12f),
        borderWidth = 1.dp
    ) {
        Ux4gResultList(
            title = "Pradhan Mantri Awas Yojana (Urban)",
            statusTag = "Approved",
            tagColorScheme = Ux4gTagColor.Success,
            actionButtonText = "View Details",
            onActionPressed = { /* Navigate to details */ },
            details = listOf(
                Ux4gResultDetail(label = "Applicant", value = "Ravi Kumar"),
                Ux4gResultDetail(label = "Application No", value = "PMAY-2025-09821"),
                Ux4gResultDetail(label = "Sanctioned Amount", value = "₹ 2,67,000", isBold = true),
                Ux4gResultDetail(label = "Disbursement Status", value = "Stage 2 Credited", valueColor = Ux4gColors.green600)
            ),
            showBottomDivider = false
        )
    }
}
```

### 2. Document Download with Verified Badge

```kotlin title="CertificateResultRow.kt"
import androidx.compose.foundation.layout.size
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.*
import com.ux4g.designsystemv1.foundation.Ux4gColors
import com.ux4g.designsystemv1.foundation.Ux4gIconComponent
import com.ux4g.designsystemv1.foundation.Ux4gIcons

@Composable
fun VerifiedCertificateRow() {
    Ux4gResultRow(
        title = "Income Certificate",
        titleTrailing = {
            Ux4gIconComponent(
                icon = Ux4gIcons.success_circle,
                contentDescription = "Verified Certificate",
                tint = Ux4gColors.green600,
                modifier = Modifier.size(18.dp)
            )
        },
        actionButtonText = "Download",
        actionButtonIcon = Ux4gIcons.upload,
        onActionPressed = { /* Initiate download */ },
        details = listOf(
            Ux4gResultDetail(label = "Reference Number", value = "INC-2026-MH-04127"),
            Ux4gResultDetail(label = "Issued Date", value = "05 Apr 2026"),
            Ux4gResultDetail(label = "Valid Till", value = "05 Apr 2027"),
            Ux4gResultDetail(label = "Issuing Authority", value = "Tehsildar Office, Pune")
        )
    )
}
```

<h2><MIcon name="settings" /> Parameters</h2>

### `Ux4gResultList` / `Ux4gResultRow` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `title` <span className="text-red-500 font-bold">*</span> | `String` | Primary heading title of the result row item. | `—` |
| `modifier` | `Modifier` | Compose modifier applied to the outer container. | `Modifier` |
| `titleTrailing` | `(@Composable () -> Unit)?` | Optional composable trailing the title (e.g. verified icon). | `null` |
| `statusTag` | `String?` | Optional status text displayed inside a rectangular tonal `Ux4gTag`. | `null` |
| `tagColorScheme` | `Ux4gTagColor` | Color scheme for the status tag. | `Ux4gTagColor.Neutral` |
| `metadataSegments` | `List<Ux4gPillSegment>?` | List of metadata pill segments displayed in a unified pill tag. | `null` |
| `customMetadata` | `(@Composable () -> Unit)?` | Custom composable replacement for metadata tags. | `null` |
| `actionButtonText` | `String?` | Label text for the outline action button on the right. | `null` |
| `actionLeading` | `(@Composable () -> Unit)?` | Optional composable rendered immediately before the action button. | `null` |
| `onActionPressed` | `(() -> Unit)?` | Callback invoked when the action button is clicked. | `null` |
| `actionButtonIcon` | `Ux4gIcon?` | Optional leading icon rendered inside the action button. | `null` |
| `actionButtonColor` | `Color?` | Custom color override for the action button border and content. | `null` |
| `details` | `List<Ux4gResultDetail>` | List of detail items rendered in a grid when expanded. | `emptyList()` |
| `expandedChild` | `(@Composable () -> Unit)?` | Custom composable placed below the details grid when expanded. | `null` |
| `detailsColumns` | `Int` | Number of columns for laying out the details grid. | `2` |
| `initialExpanded` | `Boolean` | Whether the item is expanded by default. | `false` |
| `onToggle` | `((Boolean) -> Unit)?` | Callback triggered when the expanded/collapsed state changes. | `null` |
| `showBottomDivider` | `Boolean` | Whether to render a horizontal divider below the row. | `true` |
| `contentPadding` | `PaddingValues` | Inner padding for the header and expanded content. | `PaddingValues(16.dp)` |
| `colors` | `Ux4gResultListColors` | Color configuration for titles, labels, values, and expand arrows. | `Ux4gResultListDefaults.colors()` |

### `Ux4gResultDetail` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `label` <span className="text-red-500 font-bold">*</span> | `String` | Descriptor title (e.g., `"Application No"`, `"Date"`). | `—` |
| `value` <span className="text-red-500 font-bold">*</span> | `String` | Value string to display. | `—` |
| `icon` | `Ux4gIcon?` | Optional icon preceding the value string. | `null` |
| `valueColor` | `Color?` | Custom text and icon color for this value. | `null` |
| `isBold` | `Boolean` | Whether the value text is rendered with bold typography. | `false` |
| `customValueWidget` | `(@Composable () -> Unit)?` | Custom composable override for the value content. | `null` |
