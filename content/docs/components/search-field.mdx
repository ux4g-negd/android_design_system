# Search Field (`Ux4gSearchField`)

The UX4G Search Field component provides an intuitive search bar for discovering government welfare schemes, tracking application statuses, navigating civil service portals, and filtering dense data listings.

### Key Capabilities

- **Instant Autocomplete & Dropdown Suggestions**: Real-time suggestion popup with customizable matching algorithms (`Contains`, `StartsWith`, `StartsWithPerTerm`) and highlighting (`"Searching for '...'"`).
- **Search Variants**: Standard input field (`BasicSearch`), search bar with integrated CTA button (`SearchWithSubmit`), and predictive search (`Autocomplete`).
- **Interactive Controls**: Built-in voice search trigger (`showVoiceIcon`), dynamic one-tap clear button (`showClearIcon`), and inline progress loader (`isLoading`).
- **Validation & Size Support**: Contextual statuses (`Default`, `Success`, `Warning`, `Error`) with captions and 4 size tiers (`Small`, `Medium`, `Large`, `XL`).

Import from `com.ux4g.designsystemv1.components.searchfield.*`.

### 1. Basic Search with Voice and Clear Handlers

```kotlin title="CitizenPortalSearch.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.searchfield.Ux4gSearchField
import com.ux4g.designsystemv1.components.searchfield.Ux4gSearchFieldSize

@Composable
fun CitizenPortalSearchSection() {
    var searchQuery by remember { mutableStateOf("") }

    Column(
        modifier = Modifier.padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        Ux4gSearchField(
            value = searchQuery,
            onValueChange = { searchQuery = it },
            label = "Universal Search",
            placeholder = "Search schemes, certificates, or grievance status...",
            size = Ux4gSearchFieldSize.Medium,
            showVoiceIcon = true,
            showClearIcon = true,
            onVoiceClick = {
                // Launch Android SpeechRecognizer Intent
            },
            onClearClick = {
                searchQuery = ""
            }
        )
    }
}
```

### 2. Autocomplete Scheme Search with Submit Button

```kotlin title="SchemeAutocompleteSearch.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.searchfield.*

@Composable
fun SchemeSearchWithSuggestions(
    onSchemeSelected: (String) -> Unit
) {
    var searchQuery by remember { mutableStateOf("") }
    val schemeList = remember {
        listOf(
            "Pradhan Mantri Awas Yojana (PMAY)",
            "Pradhan Mantri Jan Dhan Yojana (PMJDY)",
            "Ayushman Bharat - PMJAY",
            "Kisan Samman Nidhi (PM-KISAN)",
            "National Social Assistance Programme"
        )
    }

    Ux4gSearchField(
        value = searchQuery,
        onValueChange = { searchQuery = it },
        variant = Ux4gSearchFieldVariant.Autocomplete,
        filterType = Ux4gSearchFilterType.Contains,
        label = "Government Welfare Schemes",
        placeholder = "Type scheme name...",
        options = schemeList,
        onOptionSelected = { selectedScheme ->
            searchQuery = selectedScheme
            onSchemeSelected(selectedScheme)
        },
        onSubmitClick = { query ->
            onSchemeSelected(query)
        }
    )
}
```

### `Ux4gSearchFieldVariant` Reference

| Variant | Description |
| :--- | :--- |
| `BasicSearch` | Standard single-row search field with trailing voice and clear icons. |
| `SearchWithSubmit` | Search field attached to a right-aligned dedicated search submit button. |
| `Autocomplete` | Search field that triggers a floating popup with filtered suggestion options. |

---

### `Ux4gSearchFieldSize` Reference

| Size | Height (`Dp`) | Typical Usage |
| :--- | :--- | :--- |
| `Small` | `32.dp` | Compact table filters, toolbar search, and high-density headers |
| `Medium` | `40.dp` | Standard application form and search bars |
| `Large` | `48.dp` | Primary screen search bars and mobile top headers |
| `XL` | `56.dp` | Prominent home landing page hero search inputs |

---

### `Ux4gSearchFilterType` Reference

| Filter Type | Matching Behavior |
| :--- | :--- |
| `Contains` | Matches any option containing the search substring anywhere in the label. |
| `StartsWith` | Matches options starting with the search query from the first character. |
| `StartsWithPerTerm` | Tokenizes query words and matches options where each term matches word starts. |

---

### `Ux4gSearchFieldStatus` Reference

| Status | Border / Text Color | Context |
| :--- | :--- | :--- |
| `Default` | `Ux4gColors.neutral300` / `primary` | Normal idle or focused search field |
| `Success` | `Ux4gColors.green600` | Successfully verified search parameter |
| `Warning` | `Ux4gColors.secondary600` | Cautionary or limited results query |
| `Error` | `Ux4gTheme.colorScheme.error` | Invalid query format or failed search parameter |
