# Feedback Form Suite (`Ux4gFeedbackForm`)

The UX4G Feedback Form suite provides citizen sentiment and satisfaction rating components with confirmation screens, improvement tag chips, multiline remarks, and skip callbacks:
1. **Star Rating Feedback Form (`Ux4gFeedbackFormStar`)**: 5-star interactive rating with dynamic low/high color thresholds, improvement category chips, and comment box.
2. **CSAT Satisfaction Form (`Ux4gFeedbackFormCsat`)**: 5-point sentiment face rating scale with color-coded feedback states and descriptive scale labels (`← Bad`, `Good →`).
3. **NPS Recommendation Form (`Ux4gFeedbackFormNps`)**: Net Promoter Score (0 to 10) horizontal scale with low (0-3), medium (4-6), and high (7-10) score highlights.

Import from `com.ux4g.designsystemv1.components.feedback.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Feedback Showcase Example"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.feedback.Ux4gFeedbackFormCsat
import com.ux4g.designsystemv1.components.feedback.Ux4gFeedbackFormNps
import com.ux4g.designsystemv1.components.feedback.Ux4gFeedbackFormStar

@Composable
fun FeedbackShowcaseScreen() {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(24.dp)
    ) {
        // 1. Star Feedback Form
        Ux4gFeedbackFormStar(
            improvementOptions = listOf("Service Speed", "Document Upload", "Payment Gateway", "UI Clarity"),
            onSubmit = { rating, chips, comment ->
                // Process 5-star feedback
            },
            onSkip = { /* Skip */ }
        )

        // 2. CSAT Sentiment Form
        Ux4gFeedbackFormCsat(
            onSubmit = { score, comment ->
                // Process 1-5 CSAT
            },
            onSkip = { /* Skip */ }
        )

        // 3. NPS 0-10 Form
        Ux4gFeedbackFormNps(
            onSubmit = { score, comment ->
                // Process NPS score
            },
            onSkip = { /* Skip */ }
        )
    }
}
```

<h2><MIcon name="settings" /> Parameters</h2>

### 1. `Ux4gFeedbackFormStar` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `improvementOptions` <span className="text-red-500 font-bold">*</span> | `List<String>` | List of selectable improvement tag chips. | — |
| `onSubmit` <span className="text-red-500 font-bold">*</span> | `(rating: Int, selectedChips: List<String>, comment: String) -> Unit` | Callback with selected star rating (1-5), chips, and comment. | — |
| `modifier` | `Modifier` | Compose layout modifier applied to outer card container. | `Modifier` |
| `minWords` | `Int` | Minimum word count required in comment before submit enables. | `0` |
| `maxLength` | `Int` | Maximum character length allowed in comment. | `200` |
| `onSkip` | `(() -> Unit)?` | Optional callback when citizen taps the skip button. | `null` |
| `onCloseSuccess` | `(() -> Unit)?` | Callback invoked when citizen closes the success screen. | `null` |
| `chipBorderRadius` | `Dp` | Corner radius of the improvement tag chips. | `4.dp` |
| `title` | `String` | Form title heading prompt. | `"Rate your experience"` |
| `improvementTitle` | `String` | Section title above the improvement chips. | `"What can we improve?"` |
| `commentPlaceholder` | `String` | Placeholder text inside multiline comment text area. | `"Tell us more about your experience"` |
| `submitButtonText` | `String` | Label text on the primary submit button. | `"Submit"` |
| `skipButtonText` | `String` | Label text on the optional skip button. | `"Skip"` |
| `successTitle` | `String` | Headline text displayed on success confirmation screen. | `"Feedback submitted"` |
| `successMessage` | `String` | Descriptive message on success confirmation screen. | `"Thank you for your feedback. This helps improve government services."` |
| `ratingIcon` | `Ux4gIcon` | Icon rendered for rating stars. | `Ux4gIcons.Star` |
| `successIcon` | `Ux4gIcon` | Icon rendered on success confirmation. | `Ux4gIcons.ThumbUp` |
| `lowRatingColor` | `Color` | Color applied to stars with rating at or below `lowRatingThreshold`. | `Ux4gColors.red600` |
| `highRatingColor` | `Color` | Color applied to stars with rating above `lowRatingThreshold`. | `Ux4gColors.yellow600` |
| `lowRatingThreshold` | `Int` | Star index cutoff for low vs high rating colors. | `2` |
