<h2><MIcon name="settings" /> Parameters</h2>

### `Ux4gFeedbackFormStar` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `title` <span className="text-red-500 font-bold">*</span> | `String` | Headline prompt asking citizen for review. | `—` |
| `onRatingSubmit` <span className="text-red-500 font-bold">*</span> | `(Int, String) -> Unit` | Callback providing rating score (1-5) and remarks. | `—` |
| `subtitle` | `String?` | Optional secondary instruction message. | `null` |
| `showCommentField` | `Boolean` | Whether to render multiline remarks text area. | `true` |
| `modifier` | `Modifier` | Compose layout modifier. | `Modifier` |
