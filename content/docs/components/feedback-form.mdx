<h2><MIcon name="code" /> 1. Star Rating Form (`Ux4gFeedbackFormStar`)</h2>

```kotlin
import com.ux4g.designsystemv1.components.feedback.Ux4gFeedbackFormStar
import androidx.compose.runtime.mutableIntStateOf
import androidx.compose.runtime.remember

var starRating by remember { mutableIntStateOf(5) }

Ux4gFeedbackFormStar(
    title = "Rate your service experience",
    rating = starRating,
    onRatingChange = { starRating = it },
    onSubmit = { rating, remarks -> /* Submit */ }
)
```
