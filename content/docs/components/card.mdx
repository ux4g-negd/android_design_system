<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Compose Example"
import com.ux4g.designsystemv1.components.Ux4gCard
import com.ux4g.designsystemv1.components.Ux4gCardVariant
import com.ux4g.designsystemv1.components.buttons.Ux4gButton
import androidx.compose.material3.Text

Ux4gCard(
    title = "Application #109283",
    subtitle = "Submitted on 12 Sep 2026",
    variant = Ux4gCardVariant.Elevated,
    onClick = { /* Open detail */ }
) {
    Text("Status: Document Verification in Progress")
    Ux4gButton(
        text = "Track Application",
        onClick = { /* Navigate */ },
        modifier = Modifier.padding(top = 8.dp)
    )
}
```

<h2><MIcon name="settings" /> Parameters</h2>

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `String?` | `null` | Header title |
| `subtitle` | `String?` | `null` | Secondary supporting text |
| `variant` | `Ux4gCardVariant` | `Elevated` | Visual style (`Elevated`, `Outlined`, `Filled`) |
| `onClick` | `(() -> Unit)?` | `null` | Click listener (makes card clickable with ripple) |
| `content` | `@Composable ColumnScope.() -> Unit` | **Required** | Inner card composable content |
