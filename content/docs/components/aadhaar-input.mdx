# Aadhaar Input (`Ux4gAadhaarInputField`)

The `Ux4gAadhaarInputField` is a specialized citizen identity input component designed specifically for 12-digit Indian Aadhaar numbers.

It features:
- **Auto-Formatting**: Automatically chunks raw numeric entry into `XXXX XXXX XXXX` (space inserted after every 4 digits).
- **Numeric-Only Filtering**: Rejects any non-digit input automatically.
- **Verhoeff Checksum Algorithm**: Validates the 12th checksum digit in real-time according to official UIDAI specifications.
- **Dynamic Status Updates**: Automatically transitions to `Ux4gInputFieldStatus.Success` ("Valid Aadhaar number") or `Ux4gInputFieldStatus.Error` ("Please enter a valid Aadhaar number") upon entering 12 digits.

Import from `com.ux4g.designsystemv1.components.inputfield.Ux4gAadhaarInputField`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Aadhaar Verification Example"
import androidx.compose.foundation.layout.*
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Badge
import androidx.compose.material.icons.filled.Close
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.inputfield.Ux4gAadhaarInputField
import com.ux4g.designsystemv1.components.inputfield.Ux4gInputFieldSize

@Composable
fun AadhaarVerificationScreen() {
    var aadhaarInput by remember { mutableStateOf("") }

    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        Ux4gAadhaarInputField(
            value = aadhaarInput,
            onValueChange = { formatted -> 
                aadhaarInput = formatted 
            },
            label = "Aadhaar Card Number",
            required = true,
            size = Ux4gInputFieldSize.Medium,
            leadingIcon = Icons.Default.Badge,
            trailingIcon = if (aadhaarInput.isNotEmpty()) Icons.Default.Close else null,
            onTrailingIconPressed = { aadhaarInput = "" }
        )
    }
}
```

<h2><MIcon name="check_circle" /> Verhoeff Validation Utility</h2>

`Ux4gAadhaarInputField` exposes standalone helper utilities for programmatic formatting and checksum validation:

```kotlin
// Validate Aadhaar number programmatically
val isValid = Ux4gAadhaarInputField.validateAadhaar("999941057058") // Returns true

// Format raw 12 digits to grouped string
val formatted = Ux4gAadhaarInputField.formatAadhaar("999941057058") // Returns "9999 4105 7058"
```
