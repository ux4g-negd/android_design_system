# Carousel Suite (`Ux4gCarousel`)

The UX4G Carousel suite provides production-ready horizontal paging banners with smooth spring animations, auto-play timers, and animated dot/capsule pagination:
1. **Hero Banner Carousel (`Ux4gHeroCarouselSlide`)**: Vibrant multi-color gradient slide with category badge, bold headline, description, and white action button.
2. **Image Gallery Carousel (`Ux4gImageCarouselSlide`)**: Full-bleed photo slide with dark gradient overlay, category tag, headline, and subtitle.
3. **Custom Content Carousel**: Dynamic carousel accepting any custom composable slide builder with configurable heights and page transitions.

Import from `com.ux4g.designsystemv1.components.Ux4gCarousel`.

                        onButtonClick = { /* handle action */ }
                    )
                }
            )
        )

        // 2. Image Gallery Overlay Carousel

            items = listOf(
                {

<h2><MIcon name="settings" /> Parameters</h2>

### 1. `Ux4gCarousel` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `items` <span className="text-red-500 font-bold">*</span> | `List<@Composable () -> Unit>` | List of composable slide items to render. | — |
| `modifier` | `Modifier` | Compose layout modifier applied to the carousel root container. | `Modifier` |
| `autoPlay` | `Boolean` | Whether the carousel automatically cycles through slide pages. | `true` |
| `autoPlayIntervalMs` | `Long` | Time in milliseconds between automatic slide transitions. | `3000L` |
| `showPagination` | `Boolean` | Whether to display the dot pagination indicator at the bottom. | `true` |
| `showPaginationArrows` | `Boolean` | Whether to show left/right arrow buttons alongside pagination dots. | `true` |
| `height` | `Dp` | Fixed height of the carousel container. | `240.dp` |
| `viewportFraction` | `Float` | Fraction of the viewport each page should occupy (`1.0f` for full width). | `1.0f` |
| `contentPadding` | `PaddingValues` | Inner padding surrounding pages in viewport. | `PaddingValues(0.dp)` |
| `pageSpacing` | `Dp` | Spacing between consecutive slide pages. | `0.dp` |
| `activePaginationColor` | `Color` | Fill color for the active elongated pill indicator. | `Ux4gColors.primary` |
| `inactivePaginationColor` | `Color` | Fill color for inactive dot indicators. | `Ux4gColors.primary100` |
| `paginationArrowBackgroundColor` | `Color` | Circular background color for previous/next arrow buttons. | `Color(0xFFDCD6FD)` |
| `paginationArrowColor` | `Color` | Icon tint color for navigation arrow chevrons. | `Ux4gColors.primary` |
| `paginationVariant` | `Ux4gPaginationVariant` | Visual container style: `Default` (transparent) or `Capsule` (white pill). | `Ux4gPaginationVariant.Default` |
| `paginationSize` | `Ux4gPaginationSize` | Sizing preset: `Small` or `Medium`. | `Ux4gPaginationSize.Small` |
| `onPageChange` | `((Int) -> Unit)?` | Callback triggered whenever the current active page index changes. | `null` |
