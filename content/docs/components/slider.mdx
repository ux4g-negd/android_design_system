# Slider (`Ux4gSlider` / `Ux4gRangeSlider`)

The UX4G Slider component enables users to select continuous or discrete values along a track. It is ideal for selecting loan amounts, subsidy tenures, citizen age criteria, income ranges, and value thresholds.

### Key Capabilities

- **Single & Range Sliders**: `Ux4gSlider` for single-value selection and `Ux4gRangeSlider` for dual-thumb closed range selection (`ClosedFloatingPointRange<Float>`).
- **Tick Marks & Numerical Values**: Automatic graduation ticks and value labels with `showMarksAndValues = true` and configurable step intervals (`steps`).
- **Interactive Tooltip Indicator**: Floating tooltip bubble (`showIndicator = true`) displaying live values directly above the sliding thumb.
- **Labels & Validation Captions**: Form field labels with required asterisk (`*`), info icons (`labelIcon`), start/end labels, and status captions (`Helper`, `Error`, `Warning`, `Success`).
- **Size Options**: `Small` (16dp thumb, 4dp track) and `Medium` (20dp thumb, 6dp track).

Import from `com.ux4g.designsystemv1.components.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

### 1. Loan Amount Selection with Live Value Summary

```kotlin title="LoanCalculatorSlider.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.Ux4gSlider
import com.ux4g.designsystemv1.components.Ux4gSliderCaptionVariant
import com.ux4g.designsystemv1.components.Ux4gSliderSize
import com.ux4g.designsystemv1.foundation.Ux4gIcons

@Composable
fun LoanAmountCalculator() {
    var amount by remember { mutableFloatStateOf(50000f) }

    Column(
        modifier = Modifier.padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        Ux4gSlider(
            value = amount,
            onValueChange = { amount = it },
            valueRange = 10000f..500000f,
            steps = 48,
            size = Ux4gSliderSize.Medium,
            label = "Sanctioned Loan Amount",
            isRequired = true,
            labelIcon = Ux4gIcons.info_circle,
            startValueText = "₹ 10,000",
            endValueText = "₹ 5,00,000",
            showIndicator = true,
            showMarksAndValues = false,
            caption = "Repayment tenure: 12 to 60 Months",
            captionVariant = Ux4gSliderCaptionVariant.Helper
        )
    }
}
```

### 2. Dual-Thumb Range Slider (Eligibility Age Criteria)

```kotlin title="AgeRangeFilter.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.Ux4gRangeSlider
import com.ux4g.designsystemv1.components.Ux4gSliderCaptionVariant
import com.ux4g.designsystemv1.components.Ux4gSliderSize

@Composable
fun AgeEligibilityRangeFilter() {
    var ageRange by remember { mutableStateOf(21f..60f) }

    Ux4gRangeSlider(
        value = ageRange,
        onValueChange = { ageRange = it },
        valueRange = 18f..80f,
        steps = 30,
        size = Ux4gSliderSize.Medium,
        label = "Applicant Age Range",
        startValueText = "Min: 18 yrs",
        endValueText = "Max: 80 yrs",
        showIndicator = true,
        showMarksAndValues = true,
        caption = "Eligible age bracket for state pension scheme",
        captionVariant = Ux4gSliderCaptionVariant.Success
    )
}
```

### `Ux4gSlider` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `value` <span className="text-red-500 font-bold">*</span> | `Float` | Current slider position value. | `—` |
| `onValueChange` <span className="text-red-500 font-bold">*</span> | `(Float) -> Unit` | Callback triggered when the slider value changes. | `—` |
| `modifier` | `Modifier` | Compose modifier applied to the outer layout container. | `Modifier` |
| `valueRange` | `ClosedFloatingPointRange<Float>` | Minimum and maximum values allowed on the track. | `0f..100f` |
| `steps` | `Int` | Number of discrete snap points between bounds. | `0` |
| `size` | `Ux4gSliderSize` | Slider thumb and track dimensions (`Small`, `Medium`). | `Ux4gSliderSize.Small` |
| `enabled` | `Boolean` | Controls interactive touch dragging and disabled opacity. | `true` |
| `label` | `String?` | Title text displayed above the track. | `null` |
| `isRequired` | `Boolean` | Displays a red asterisk (`*`) next to the label when `true`. | `false` |
| `labelIcon` | `Ux4gIcon?` | Optional icon rendered next to the label. | `null` |
| `startValueText` | `String?` | Left boundary label text displayed above the track. | `null` |
| `endValueText` | `String?` | Right boundary label text displayed above the track. | `null` |
| `caption` | `String?` | Descriptive helper or validation message below the track. | `null` |
| `captionVariant` | `Ux4gSliderCaptionVariant` | Severity variant for caption text and status icons. | `Ux4gSliderCaptionVariant.Helper` |
| `showMarksAndValues` | `Boolean` | Whether to draw graduation tick marks and numbers below the track. | `false` |
| `showInputFields` | `Boolean` | Renders editable numeric input fields for direct value entry. | `false` |
| `showValueLabels` | `Boolean` | Displays formatted text value summaries above track. | `false` |
| `showIndicator` | `Boolean` | Renders a floating tooltip bubble above the thumb while sliding. | `false` |
| `valueFormatter` | `(Float) -> String` | Custom formatting function for numeric label text. | `{ "${it.toInt()}%" }` |
| `interactionSource` | `MutableInteractionSource` | Interaction stream for press and drag state tracking. | `remember { MutableInteractionSource() }` |
