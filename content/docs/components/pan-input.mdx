# PAN Card Input (`Ux4gPanInputField`)

The `Ux4gPanInputField` is a specialized citizen identity input component designed specifically for 10-character Indian Permanent Account Numbers (PAN cards).

It features:
- **Auto-Uppercase Conversion**: Automatically transforms entered alphanumeric characters to uppercase format (`ABCDE1234F`).
- **Alphanumeric Filter**: Disallows spaces and special characters.
- **Income Tax PAN Regex Validation**: Validates the official pattern: 5 letters + 4 digits + 1 letter (`^[A-Z]{5}[0-9]{4}[A-Z]{1}$`).
- **Dynamic Status Updates**: Automatically transitions to `Ux4gInputFieldStatus.Success` ("Valid PAN number") or `Ux4gInputFieldStatus.Error` ("Please enter a valid PAN number") upon reaching 10 characters.

Import from `com.ux4g.designsystemv1.components.inputfield.Ux4gPanInputField`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="PAN Verification Example"
import androidx.compose.foundation.layout.*
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Close
import androidx.compose.material.icons.filled.CreditCard
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.inputfield.Ux4gInputFieldSize
import com.ux4g.designsystemv1.components.inputfield.Ux4gPanInputField

@Composable
fun PanVerificationScreen() {
    var panInput by remember { mutableStateOf("") }

    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        Ux4gPanInputField(
            value = panInput,
            onValueChange = { cleanPan -> 
                panInput = cleanPan 
            },
            label = "Permanent Account Number",
            required = true,
            size = Ux4gInputFieldSize.Medium,
            leadingIcon = Icons.Default.CreditCard,
            trailingIcon = if (panInput.isNotEmpty()) Icons.Default.Close else null,
            onTrailingIconPressed = { panInput = "" }
        )
    }
}
```

<h2><MIcon name="check_circle" /> PAN Regex Validation Utility</h2>

`Ux4gPanInputField` provides programmatic verification:

```kotlin
// Validate PAN string programmatically
val isValid = Ux4gPanInputField.validatePan("ABCDE1234F") // Returns true
val isInvalid = Ux4gPanInputField.validatePan("12345ABCDE") // Returns false

// Format raw input into uppercase 10-char limit
val formatted = Ux4gPanInputField.formatPan("abcde1234f") // Returns "ABCDE1234F"
```
