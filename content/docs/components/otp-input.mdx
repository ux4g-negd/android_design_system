<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Compose Example"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.Ux4gOtpInput
import com.ux4g.designsystemv1.components.inputfield.Ux4gInputFieldStatus

@Composable
fun OtpVerificationScreen() {
    var otp by remember { mutableStateOf("") }
    var status by remember { mutableStateOf(Ux4gInputFieldStatus.Default) }

    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        Ux4gOtpInput(
            value = otp,
            onValueChange = { 
                otp = it 
                if (it.length == 6) {
                    // Trigger verify API
                }
            },
            label = "Enter Verification Code",
            length = 6,
            status = status,
            onComplete = { fullOtp ->
                verifyOtpApi(fullOtp)
            },
            onResendClick = {
                resendOtpApi()
            }
        )
    }
}
```

<h2><MIcon name="settings" /> Parameters</h2>

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `value` <span className="text-red-500 font-bold">*</span> | `String` | Current OTP string value. | `—` |
| `onValueChange` <span className="text-red-500 font-bold">*</span> | `(String) -> Unit` | Callback invoked on each digit change. | `—` |
| `label` | `String?` | Header title label above OTP boxes. | `null` |
| `length` | `Int` | Number of OTP digit boxes (typically 4 or 6). | `6` |
| `status` | `Ux4gInputFieldStatus` | Status state (`Default`, `Success`, `Error`, `Warning`). | `Ux4gInputFieldStatus.Default` |
| `caption` | `String?` | Helper, error, or timer caption text below boxes. | `null` |
| `onComplete` | `((String) -> Unit)?` | Fires automatically when citizen enters all digits. | `null` |
| `onResendClick` | `(() -> Unit)?` | Resend OTP action trigger callback. | `null` |
| `enabled` | `Boolean` | Interactive enabled state. | `true` |
| `modifier` | `Modifier` | Compose layout modifier. | `Modifier` |
