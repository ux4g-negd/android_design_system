# Journey Timeline (`Ux4gJourneyTimeline`)

The UX4G Journey Timeline component visualizes multi-stage citizen workflows, application processes, and milestone checkpoints in both **Vertical** and **Horizontal** orientations.

It provides step indicators (completed checks, active rings, upcoming nodes), connecting lines, date tags, helper text, inline status pills (e.g. `2 days remaining | Pending`), and customizable header sections.

Import from `com.ux4g.designsystemv1.components.journeytimeline.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Citizen Scheme Tracking Example"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.journeytimeline.*
import com.ux4g.designsystemv1.foundation.Ux4gIcons

@Composable
fun SchemeApplicationTracker() {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(24.dp)
    ) {
        // Vertical Timeline Tracker
        Ux4gJourneyTimeline(
            header = Ux4gJourneyHeader(
                title = "Application Progress",
                description = "Track the status of your scholarship application in real time",
                icon = Ux4gIcons.Info
            ),
            orientation = Ux4gJourneyOrientation.Vertical,
            steps = listOf(
                Ux4gJourneyStep(
                    state = Ux4gJourneyStepState.Completed,
                    date = "12 Aug, 10:30 AM",
                    tag = "Verified",
                    title = "Application Submitted",
                    helpingText = "All documents uploaded and digitally signed."
                ),
                Ux4gJourneyStep(
                    state = Ux4gJourneyStepState.Completed,
                    date = "13 Aug, 02:15 PM",
                    tag = "Approved",
                    title = "Identity Verification",
                    helpingText = "Aadhaar and academic certificates verified."
                ),
                Ux4gJourneyStep(
                    state = Ux4gJourneyStepState.Current,
                    date = "15 Aug, 11:00 AM",
                    tag = "In Progress",
                    title = "Under Review by Verification Officer",
                    helpingText = "Application is currently pending nodal officer sign-off.",
                    status = Ux4gJourneyStepStatus(
                        text = "2 days remaining",
                        badgeText = "Pending",
                        badgePosition = Ux4gJourneyBadgePosition.Bottom
                    )
                ),
                Ux4gJourneyStep(
                    state = Ux4gJourneyStepState.Upcoming,
                    date = "Pending",
                    tag = "Upcoming",
                    title = "Direct Benefit Transfer (DBT)",
                    helpingText = "Disbursement directly into Aadhaar linked bank account."
                )
            )
        )
    }
}
```

<h2><MIcon name="settings" /> Parameters</h2>

### 1. `Ux4gJourneyTimeline` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `steps` <span className="text-red-500 font-bold">*</span> | `List<Ux4gJourneyStep>` | List of milestone checkpoints in chronological order. | — |
| `modifier` | `Modifier` | Compose layout modifier applied to outer container. | `Modifier` |
| `header` | `Ux4gJourneyHeader?` | Optional header section with title, description, and action icon. | `null` |
| `currentStep` | `Int?` | Zero-based index of the active step. When specified, automatically marks earlier steps as `Completed`, current index as `Current`, and later steps as `Upcoming`. | `null` |
| `orientation` | `Ux4gJourneyOrientation` | Layout direction: `Vertical` or `Horizontal`. | `Ux4gJourneyOrientation.Vertical` |
| `indicatorSize` | `Dp` | Diameter of the step circle indicators. | `20.dp` |
| `lineWidth` | `Dp` | Thickness of the connecting progression line. | `3.dp` |
| `indicatorCardSpacing` | `Dp` | Horizontal gap between indicator column and cards in vertical orientation, or vertical gap to card in horizontal orientation. | `12.dp` |
| `stepSpacing` | `Dp` | Space between adjacent step cards. | `12.dp` |
| `activeColor` | `Color?` | Color for completed/current indicators and lines. | `Ux4gColors.primary` |
| `inactiveColor` | `Color?` | Color for upcoming indicators and connecting lines. | `Ux4gColors.neutral900 (25% opacity)` |
| `cardBorderRadius` | `Dp` | Corner radius of the step card containers. | `8.dp` |
| `cardPadding` | `PaddingValues` | Inner padding of step cards. | `PaddingValues(horizontal = 16.dp, vertical = 12.dp)` |
| `cardColor` | `Color?` | Background color override for all step cards. | `Ux4gColors.neutral0` |
| `cardBorderColor` | `Color?` | Border color override for all step cards. | `Ux4gColors.neutral900 (10% opacity)` |
| `dateStyle` | `TextStyle?` | Text style override for dates across all steps. | `null` |
| `titleStyle` | `TextStyle?` | Text style override for titles across all steps. | `null` |

### 5. Enums Reference

```kotlin
enum class Ux4gJourneyOrientation {
    Vertical,   // Continuous vertical timeline layout
    Horizontal  // Compact horizontal milestone stepper layout
}

enum class Ux4gJourneyStepState {
    Completed,  // Filled circle with check icon, active line
    Current,    // Target concentric double-ring indicator, active line
    Upcoming    // Subtle outlined circle, muted gray line
}

enum class Ux4gJourneyBadgePosition {
    Bottom,     // Unified pill tag at bottom of step card
    TopRight    // Tag badge at top-right next to date
}
```
