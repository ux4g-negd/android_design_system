# Bottom Sheet (`Ux4gBottomSheet`)

The UX4G Bottom Sheet is an edge-anchored modal surface designed to present secondary tasks, detailed summaries, selection workflows, or contextual actions without navigating away from the current screen.

Built strictly to UX4G design tokens, it offers overflow-proof responsive scrolling with pinned footer action buttons, a rounded top container (`16.dp`), customizable header elements (icon, title, subtitle, close button), and full Dark/Light mode theme integration.

### Key Capabilities

- **4 Standard Height Presets (`Ux4gBottomSheetSize`)**:
  - `Peek` (`0.26f` / 26% screen height): Quick alerts, confirmation prompts, or minimal single-card summaries.
  - `Half` (`0.50f` / 50% screen height — default): Standard interactive workflows, short forms, or selection lists.
  - `Expanded` (`0.75f` / 75% screen height): Multi-step verification summaries, document previews, or detailed lists.
  - `Full` (`0.94f` / 94% screen height): Comprehensive multi-step forms, terms and conditions, or full-page workflows.
  - Custom explicit height (`height: Dp?`) support.
- **Pinned Bottom Action Footers**: The footer buttons remain anchored at the bottom of the screen while the middle body content scrolls smoothly, preventing action buttons from being pushed off-screen.
- **Flexible Footer Arrangements (`Ux4gBottomSheetFooterAlignment`)**:
  - `Split` / `Justified`: Dual buttons sharing equal 50% width side-by-side.
  - `Left`, `Centered`, `Right`: Standard horizontal button alignments.
  - Destructive action styling (`isDestructive = true`).
- **Complete Header Controls**: Integrated drag handle indicator pill (`32×4dp`), leading icon or composable, headline, subtle text, and dismiss close button.
- **Modal & Persistent Layouts**: `Ux4gBottomSheet` for modal overlays and `Ux4gBottomSheetLayout` for inline/embedded sheet designs.

Import from `com.ux4g.designsystemv1.components.*`.

## Complete Implementation Example

The following Jetpack Compose snippet demonstrates a citizen application status screen launching an interactive modal `Ux4gBottomSheet`:

```kotlin
package com.example.app.ui

import androidx.compose.foundation.background
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.outlined.CheckCircle
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.*
import com.ux4g.designsystemv1.foundation.Ux4gColors
import com.ux4g.designsystemv1.theme.Ux4gTheme

@Composable
fun ApplicationReviewScreen() {
    var isSheetOpen by remember { mutableStateOf(false) }

    Box(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        contentAlignment = Alignment.Center
    ) {
        Button(onClick = { isSheetOpen = true }) {
            Text("Review Application Steps")
        }

        if (isSheetOpen) {
            Ux4gBottomSheet(
                onDismissRequest = { isSheetOpen = false },
                size = Ux4gBottomSheetSize.Half,
                headerTitle = "Application Summary",
                description = "Review verified milestones before proceeding with submission.",
                primaryButtonText = "Confirm & Continue",
                secondaryButtonText = "Cancel",
                footerAlignment = Ux4gBottomSheetFooterAlignment.Split,
                onPrimaryClick = {
                    isSheetOpen = false
                    // Submit verified application
                },
                onSecondaryClick = { isSheetOpen = false }
            ) {
                Column(verticalArrangement = Arrangement.spacedBy(8.dp)) {
                    listOf(
                        "Document verification completed",
                        "Aadhaar e-KYC authenticated",
                        "Bank account linked via DBT",
                        "Income certificate validated",
                        "Final review pending signature"
                    ).forEachIndexed { index, text ->
                        Row(
                            modifier = Modifier
                                .fillMaxWidth()
                                .background(
                                    color = Ux4gColors.neutral50,
                                    shape = RoundedCornerShape(8.dp)
                                )
                                .padding(horizontal = 12.dp, vertical = 10.dp),
                            verticalAlignment = Alignment.CenterVertically,
                            horizontalArrangement = Arrangement.spacedBy(8.dp)
                        ) {
                            Icon(
                                imageVector = Icons.Outlined.CheckCircle,
                                contentDescription = null,
                                tint = Ux4gColors.green600,
                                modifier = Modifier.size(18.dp)
                            )
                            Text(
                                text = "Step \${index + 1}: \$text",
                                style = Ux4gTheme.typography.bS_default
                            )
                        }
                    }
                }
            }
        }
    }
}
```

### `Ux4gBottomSheet` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `onDismissRequest` | `() -> Unit` | Callback fired when the sheet is dismissed (scrim tap, drag down, or close button). | **Required** |
| `modifier` | `Modifier` | Compose layout modifier applied to the root sheet container. | `Modifier` |
| `sheetState` | `SheetState` | Material 3 sheet state managing expansion and collapse. | `rememberModalBottomSheetState(skipPartiallyExpanded = true)` |
| `size` | `Ux4gBottomSheetSize` | Height preset: `Peek` (26%), `Half` (50%), `Expanded` (75%), `Full` (94%). | `Ux4gBottomSheetSize.Half` |
| `height` | `Dp?` | Explicit height in Dp. Overrides `size` preset if provided. | `null` |
| `isDraggable` | `Boolean` | Whether the sheet can be swiped/dragged to dismiss. | `true` |
| `showDragHandle` | `Boolean` | Whether to display the top drag handle indicator pill (`32×4dp`). | `true` |
| `showHeader` | `Boolean` | Whether to render the top header block. | `true` |
| `headerTitle` | `String?` | Primary headline text shown in the header. | `null` |
| `headerSubtleText` | `String?` | Small muted badge text displayed to the right of the title. | `null` |
| `headerIcon` | `Ux4gIcon?` | Optional leading icon from `Ux4gIcons`. | `null` |
| `headerIconComposable` | `(@Composable () -> Unit)?` | Custom leading composable slot for header icon. | `null` |
| `description` | `String?` | Secondary descriptive text displayed below the title. | `null` |
| `showCloseButton` | `Boolean` | Whether to render the top-right close icon button. | `true` |
| `onCloseClick` | `(() -> Unit)?` | Custom close button callback (defaults to `onDismissRequest`). | `null` |
| `showHeaderDivider` | `Boolean` | Whether to display a divider line below the header. | `false` |
| `showBottomDivider` | `Boolean` | Whether to display a divider line above the pinned footer. | `false` |
| `scrollable` | `Boolean` | Enables built-in vertical scrolling for middle body content. | `true` |
| `contentPadding` | `PaddingValues` | Inner padding surrounding body content. | `PaddingValues(horizontal = 16.dp, vertical = 12.dp)` |
| `showFooter` | `Boolean` | Whether to render the pinned bottom footer row. | `true` |
| `footerAlignment` | `Ux4gBottomSheetFooterAlignment` | Horizontal alignment of footer buttons: `Split`, `Left`, `Centered`, `Right`. | `Ux4gBottomSheetFooterAlignment.Split` |
| `showPrimaryButton` | `Boolean` | Whether to show the filled primary action button. | `true` |
| `showSecondaryButton` | `Boolean` | Whether to show the outlined secondary action button. | `true` |
| `primaryButtonText` | `String` | Label text for the filled primary button. | `"Confirm"` |
| `secondaryButtonText` | `String` | Label text for the outlined secondary button. | `"Cancel"` |
| `onPrimaryClick` | `() -> Unit` | Click callback for the primary button. | `onDismissRequest` |
| `onSecondaryClick` | `() -> Unit` | Click callback for the secondary button. | `onDismissRequest` |
| `isDestructive` | `Boolean` | Renders primary button in destructive error red color. | `false` |
| `footerContent` | `(@Composable () -> Unit)?` | Custom composable slot overriding default footer buttons. | `null` |
| `containerColor` | `Color` | Surface background fill color. | `Ux4gTheme.colorScheme.surface` |
| `scrimColor` | `Color` | Color of the background scrim overlay. | `Color(0xFF0F172A).copy(alpha = 0.5f)` |
| `cornerRadius` | `Dp` | Corner rounding radius for top-left and top-right edges. | `16.dp` |
| `content` | `@Composable ColumnScope.() -> Unit` | Main scrollable body content slot of the bottom sheet. | **Required** |

### Enums & Types

#### `Ux4gBottomSheetSize`

| Variant | Screen Height Ratio | Description |
| :--- | :--- | :--- |
| `Peek` | `0.26f` (26%) | Compact height for quick prompts, status toasts, or single cards. |
| `Half` | `0.50f` (50%) | Balanced half-screen height for standard citizen tasks and forms (default). |
| `Expanded` | `0.75f` (75%) | Spacious three-quarter screen height for detailed summaries and checklists. |
| `Full` | `0.94f` (94%) | Maximum-height sheet for comprehensive document reviews and audits. |

#### `Ux4gBottomSheetFooterAlignment`

| Value | Behavior |
| :--- | :--- |
| `Split` / `Justified` | Both buttons take equal width (`50%` each) and fill the container side-by-side. |
| `Left` | Buttons aligned to the start/left edge. |
| `Centered` | Buttons centered horizontally within the footer. |
| `Right` | Buttons aligned to the end/right edge. |
