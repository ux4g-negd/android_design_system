# Toast & Snackbars (`Ux4gToast`)

The UX4G Toast and Snackbar component displays non-intrusive, transient feedback messages to inform citizens about application submissions, system status updates, validation warnings, and background process results.

### Key Capabilities

- **Semantic Feedback Categories**: Pre-styled visual indicators for `Info`, `Success`, `Warning`, `Error`, and `Slot` states.
- **Title & Supporting Description**: Emphasized bold heading with an optional secondary subtitle describing the status or error details.
- **Adaptive Layouts**: Supports `Full` layout (one-line format for tablet/desktop) and `Stacked` layout (multi-line indented format for mobile devices).
- **Interactive Action Buttons & Dismiss**: Integrated call-to-action link button (`actionText`, `onActionClick`) and optional dismiss close button (`onCloseClick`).
- **Animated Toast Host**: `Ux4gToastHost` and `Ux4gToastHostState` for coordinated top or bottom animated slide and fade overlays with auto-close timers.

Import from `com.ux4g.designsystemv1.components.Ux4gToast`.

### 1. Direct Toast Component Placement

```kotlin title="StaticToastShowcase.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.Ux4gToast
import com.ux4g.designsystemv1.components.Ux4gToastCategory

@Composable
fun ToastShowcase() {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(12.dp)
    ) {
        Ux4gToast(
            category = Ux4gToastCategory.Info,
            title = "Info message",
            subtitle = "Supporting description text."
        )

        Ux4gToast(
            category = Ux4gToastCategory.Success,
            title = "Success message",
            subtitle = "Supporting description text.",
            actionText = "View",
            onActionClick = { /* Navigate to details */ }
        )

        Ux4gToast(
            category = Ux4gToastCategory.Warning,
            title = "Warning message",
            subtitle = "Supporting description text."
        )

        Ux4gToast(
            category = Ux4gToastCategory.Error,
            title = "Error message",
            subtitle = "Supporting description text."
        )
    }
}
```

### 2. Animated Toast Host with State Management

```kotlin title="ToastHostExample.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.Ux4gToastCategory
import com.ux4g.designsystemv1.components.Ux4gToastHost
import com.ux4g.designsystemv1.components.Ux4gToastHostState
import com.ux4g.designsystemv1.components.buttons.Ux4gButton
import kotlinx.coroutines.launch

@Composable
fun ApplicationSubmissionScreen() {
    val coroutineScope = rememberCoroutineScope()
    val toastHostState = remember { Ux4gToastHostState() }

    Box(modifier = Modifier.fillMaxSize()) {
        Column(
            modifier = Modifier.padding(16.dp),
            verticalArrangement = Arrangement.spacedBy(16.dp)
        ) {
            Ux4gButton(
                text = "Submit Application",
                onClick = {
                    coroutineScope.launch {
                        toastHostState.showToast(
                            category = Ux4gToastCategory.Success,
                            title = "Success message",
                            subtitle = "Supporting description text.",
                            actionText = "Track",
                            onActionClick = { /* Track Application */ },
                            durationMillis = 3000
                        )
                    }
                }
            )
        }

        // Top-floating animated toast overlay
        Ux4gToastHost(
            hostState = toastHostState,
            isBottom = false
        )
    }
}
```

<h2><MIcon name="settings" /> Parameters</h2>

### `Ux4gToast` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `category` <span className="text-red-500 font-bold">*</span> | `Ux4gToastCategory` | Semantic tone determining icon, background tint, and action colors (`Info`, `Success`, `Warning`, `Error`, `Slot`). | `—` |
| `title` <span className="text-red-500 font-bold">*</span> | `String` | Primary bold notification heading text. | `—` |
| `modifier` | `Modifier` | Compose layout modifier applied to the toast card. | `Modifier` |
| `subtitle` | `String?` | Optional secondary description text providing supporting context. | `null` |
| `actionText` | `String?` | Optional text label for the right-aligned action trigger button. | `null` |
| `onActionClick` | `(() -> Unit)?` | Callback invoked when the citizen taps the action text. | `null` |
| `onCloseClick` | `(() -> Unit)?` | Callback triggered when the citizen taps the close (`X`) icon button. | `null` |
| `showCloseButton` | `Boolean` | Whether to render the trailing close (`X`) dismiss button. | `true` |
| `layout` | `Ux4gToastLayout?` | Layout structure: `Full` (single-line horizontal) or `Stacked` (multi-line indented for mobile). | Auto-detected |

---

### `Ux4gToastHost` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `hostState` <span className="text-red-500 font-bold">*</span> | `Ux4gToastHostState` | State object controlling current active toast display and dismissal. | `—` |
| `modifier` | `Modifier` | Compose modifier applied to the toast host container. | `Modifier` |
| `isBottom` | `Boolean` | When `true`, slides up from bottom; when `false`, slides down from top. | `false` |

---

### `Ux4gToastCategory` Reference

| Category | Background Color | Icon Tint | Standard Icon | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| `Info` | `Ux4gColors.cyan50` | `Ux4gColors.cyan500` | `Ux4gIcons.info_circle` | Informational announcements, sync status, and generic notices |
| `Success` | `Ux4gColors.green50` | `Ux4gColors.green500` | `Ux4gIcons.success_circle` | Confirmation of completed applications, uploads, and saved data |
| `Warning` | `Ux4gColors.gold50` | `Ux4gColors.gold600` | `Ux4gIcons.warning` | Session expiration warnings, pending documents, or soft limits |
| `Error` | `Ux4gColors.red50` | `Ux4gColors.red600` | `Ux4gIcons.error` | Failed network requests, authorization errors, or upload failures |
| `Slot` | `Ux4gColors.purple50` | `Ux4gColors.purple500` | `Ux4gIcons.Settings` | Custom slot or administrative system notification |
