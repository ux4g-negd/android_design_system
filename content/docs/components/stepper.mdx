# Stepper (`Ux4gStepper` / `Ux4gCompactStepper`)

The UX4G Stepper component guides citizens through multi-step forms, verification procedures, and onboarding sequences. It provides structured progress feedback through standard full-width steppers and mobile-optimized compact capsule layouts.

### Key Capabilities

- **Standard Stepper Layouts**: Supports `Horizontal` (center-line or bottom-line track) and `Vertical` orientations with customizable line styles (`Solid`, `Dashed`).
- **Compact Capsule Steppers**: Space-efficient mobile stepper (`Ux4gCompactStepper`) featuring pill indicators with 5 layout arrangements (`Linear`, `RightAligned`, `Centered`, `CenteredBetween`, `Split`).
- **Detailed Step Metadata**: Supports individual step titles, subtitles, status tags (e.g., "Completed", "In progress"), and error states (`Ux4gStepItem`).
- **Interactive Navigation**: Integrated previous/next arrow button controls with automatic boundary disabling.

Import from `com.ux4g.designsystemv1.components.steppers.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

### 1. Multi-Step Citizen Application Wizard

```kotlin title="CitizenFormWizard.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.steppers.*

@Composable
fun CitizenRegistrationWizard(currentStepIndex: Int) {
    val steps = remember {
        listOf(
            Ux4gStepItem(
                title = "Applicant Details",
                description = "Name, DOB, & Gender",
                statusLabel = "Completed"
            ),
            Ux4gStepItem(
                title = "Address & Domicile",
                description = "Permanent Address Verification",
                statusLabel = "In progress"
            ),
            Ux4gStepItem(
                title = "Income & Caste",
                description = "Certificates Upload",
                statusLabel = "Pending"
            ),
            Ux4gStepItem(
                title = "Review & Submit",
                description = "Final e-Sign Verification",
                statusLabel = "Pending"
            )
        )
    }

    Ux4gStepper(
        totalSteps = 4,
        currentStep = currentStepIndex,
        steps = steps,
        orientation = StepperOrientation.Horizontal,
        linePlacement = StepperLinePlacement.Center,
        modifier = Modifier.fillMaxWidth().padding(16.dp)
    )
}
```

### 2. Mobile Compact Capsule Stepper

```kotlin title="MobileOnboardingStepper.kt"
import androidx.compose.foundation.layout.padding
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.steppers.*

@Composable
fun MobileOnboardingFlow() {
    var step by remember { mutableIntStateOf(1) }

    val stepLabels = listOf(
        "Mobile Verification" to "Enter 6-digit OTP",
        "PAN Verification" to "Enter 10-digit PAN",
        "Bank Account" to "IFSC and Account No",
        "Set MPIN" to "Choose 4-digit Security PIN"
    )

    val currentInfo = stepLabels.getOrElse(step - 1) { "Complete" to "" }

    Ux4gCompactStepper(
        totalSteps = stepLabels.size,
        currentStep = step,
        stepLabel = currentInfo.first,
        description = currentInfo.second,
        layout = Ux4gCompactStepperLayout.Linear,
        onNext = { if (step < stepLabels.size) step++ },
        onPrevious = { if (step > 1) step-- },
        modifier = Modifier.padding(16.dp)
    )
}
```

### `Ux4gStepper` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `totalSteps` <span className="text-red-500 font-bold">*</span> | `Int` | Total number of steps in the sequence. | `—` |
| `currentStep` <span className="text-red-500 font-bold">*</span> | `Int` | Active step index (1-indexed). | `—` |
| `modifier` | `Modifier` | Compose modifier applied to the outer layout. | `Modifier` |
| `orientation` | `StepperOrientation` | Stepper orientation (`Horizontal` or `Vertical`). | `StepperOrientation.Horizontal` |
| `lineStyle` | `StepperLineStyle` | Visual connecting line style (`Solid` or `Dashed`). | `StepperLineStyle.Solid` |
| `linePlacement` | `StepperLinePlacement` | Connecting line position (`Center` or `Bottom`). | `StepperLinePlacement.Center` |
| `steps` | `List<Ux4gStepItem>` | List of step models providing titles, descriptions, and statuses. | `emptyList()` |
| `stepSize` | `Dp` | Diameter of the circular step icon indicator. | `32.dp` |
| `showLabels` | `Boolean` | Whether step titles, descriptions, and statuses are displayed. | `true` |
| `edgeLabelAlignment` | `Boolean` | In horizontal layout, aligns first step to start and last step to end. | `false` |
| `activeStepBackground` | `Boolean` | In bottom-line layout, highlights active step column with light tint. | `false` |
| `stepSpacing` | `Dp` | Spacing between steps in vertical orientation. | `24.dp` |
| `alignIconWithDescription` | `Boolean` | Offsets top step icon to align with multi-line descriptions in vertical mode. | `false` |
| `colors` | `Ux4gStepperColors` | Color palette configuration for circles, lines, and text. | `Ux4gStepperDefaults.colors()` |

---

### `StepperOrientation` & `StepperLinePlacement` Reference

| Orientation / Placement | Description |
| :--- | :--- |
| `StepperOrientation.Horizontal` | Standard horizontal layout across desktop headers and top wizard bars. |
| `StepperOrientation.Vertical` | Vertical timeline column layout with connecting lines running downward. |
| `StepperLinePlacement.Center` | Connecting line passes through the center of the step circle icons. |
| `StepperLinePlacement.Bottom` | Connecting line runs horizontally along the bottom baseline beneath labels. |

---

### `Ux4gCompactStepperLayout` Reference

| Layout Variant | Description |
| :--- | :--- |
| `Linear` | Navigation buttons flank the top capsule row, with title/desc on bottom-left. |
| `RightAligned` | Top row holds capsules and buttons; bottom-left holds step count, bottom-right holds title/desc. |
| `Centered` | Top row holds capsules; middle row holds buttons and step count; bottom holds centered title/desc. |
| `CenteredBetween` | Top row holds capsules; middle holds step count; bottom row flanks title with left/right buttons. |
| `Split` | Top row holds capsules; bottom-left holds title/desc, bottom-right holds step count & buttons. |
