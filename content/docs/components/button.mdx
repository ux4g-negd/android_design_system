# Button Suite (`Ux4gButton`)

The UX4G Button suite provides modular composable buttons tailored for citizen self-service workflows, transaction confirmations, and utility actions:
1. **Fill Button (`Ux4gButton`)**: High-emphasis solid action buttons with `Primary` brand purple and `Secondary` styles.
2. **Outline Button (`Ux4gOutlineButton`)**: Medium-emphasis bordered buttons for secondary or cancel actions.
3. **Tonal Button (`Ux4gButton` with `Tonal`)**: Low-to-medium emphasis soft-tinted background button.
4. **Text Button (`Ux4gTextButton`)**: Clean ghost button without container or border, ideal for inline actions and links.
5. **Icon Button (`Ux4gIconButton`)**: Circular and rounded icon buttons in `Filled`, `Outline`, `Text`, and `Tonal` styles.

Import from `com.ux4g.designsystemv1.components.buttons.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Button Showcase Example"
import androidx.compose.foundation.Image
import androidx.compose.foundation.layout.*
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.res.painterResource
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.buttons.Ux4gButton
import com.ux4g.designsystemv1.components.buttons.Ux4gButtonSize
import com.ux4g.designsystemv1.components.buttons.Ux4gButtonVariant
import com.ux4g.designsystemv1.components.buttons.Ux4gIconButton
import com.ux4g.designsystemv1.components.buttons.Ux4gIconButtonShape
import com.ux4g.designsystemv1.components.buttons.Ux4gIconButtonSize
import com.ux4g.designsystemv1.components.buttons.Ux4gIconButtonStyle
import com.ux4g.designsystemv1.components.buttons.Ux4gOutlineButton
import com.ux4g.designsystemv1.components.buttons.Ux4gTextButton
import com.ux4g.designsystemv1.theme.Ux4gTheme

@Composable
fun ButtonVariantsShowcase() {
    Column(
        modifier = Modifier.padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        // 1. Fill Button (Primary)
        Ux4gButton(
            text = "Proceed to Authentication",
            onClick = { /* handle click */ },
            variant = Ux4gButtonVariant.Primary,
            size = Ux4gButtonSize.Large
        )

        // 2. Fill Button (Secondary)
        Ux4gButton(
            text = "Save as Draft",
            onClick = { /* handle click */ },
            variant = Ux4gButtonVariant.Secondary,
            size = Ux4gButtonSize.Medium
        )

        // 3. Outline Button
        Ux4gOutlineButton(
            text = "Cancel Application",
            onClick = { /* handle click */ },
            size = Ux4gButtonSize.Medium
        )

        // 4. Tonal Button
        Ux4gButton(
            text = "Explore Services",
            onClick = { /* handle click */ },
            variant = Ux4gButtonVariant.Tonal,
            size = Ux4gButtonSize.Medium
        )

        // 5. Text Button
        Ux4gTextButton(
            text = "Skip for Now",
            onClick = { /* handle click */ },
            size = Ux4gButtonSize.Small
        )

        // 6. Icon Buttons in a Row
        Row(horizontalArrangement = Arrangement.spacedBy(12.dp)) {
            Ux4gIconButton(
                onClick = {},
                type = Ux4gIconButtonStyle.Filled,
                shape = Ux4gIconButtonShape.Round,
                size = Ux4gIconButtonSize.L
            ) { Text("+", style = Ux4gTheme.typography.hS_strong) }

            Ux4gIconButton(
                onClick = {},
                type = Ux4gIconButtonStyle.Outline,
                shape = Ux4gIconButtonShape.Rounded,
                size = Ux4gIconButtonSize.L
            ) { Text("⚙", style = Ux4gTheme.typography.hS_strong) }

            Ux4gIconButton(
                onClick = {},
                type = Ux4gIconButtonStyle.Tonal,
                shape = Ux4gIconButtonShape.Round,
                size = Ux4gIconButtonSize.L
            ) { Text("↗", style = Ux4gTheme.typography.hS_strong) }

            Ux4gIconButton(
                onClick = {},
                type = Ux4gIconButtonStyle.Text,
                size = Ux4gIconButtonSize.L
            ) { Text("✕", style = Ux4gTheme.typography.hS_strong) }
        }
    }
}
```

### `Ux4gButtonVariant` Enum

| Variant | Tone & Fill | Border | Text / Icon Color | Recommended Context |
| :--- | :--- | :--- | :--- | :--- |
| `Primary` | Solid Brand Purple (`#4A2BC2`) | None | White (`#FFFFFF`) | Primary high-priority action per screen (Submit, Proceed, Pay) |
| `Secondary` | Solid Secondary Amber / Gold | None | Dark / On-Secondary | Secondary alternative actions (Save Draft, Next Step) |
| `Outline` | Transparent | `1.dp` Brand Purple | Brand Purple | Low-emphasis complementary actions (Cancel, Back, Reset) |
| `Text` | Transparent | None | Brand Purple | Ghost actions, inline links, dialog footer dismissals |
| `Tonal` | Soft Tinted (`primary50`) | None | Brand Purple | Low-to-medium emphasis utility actions (Filters, Explore) |
