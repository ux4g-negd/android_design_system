<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Compose Example"
import androidx.compose.runtime.Composable
import com.ux4g.designsystemv1.components.buttons.Ux4gButton
import com.ux4g.designsystemv1.components.buttons.Ux4gButtonVariant
import com.ux4g.designsystemv1.components.buttons.Ux4gButtonSize

@Composable
fun SubmitButtonExample() {
    Ux4gButton(
        text = "Proceed to Verification",
        onClick = { /* Handle action */ },
        variant = Ux4gButtonVariant.Primary,
        size = Ux4gButtonSize.Large
    )
}
```

<h2><MIcon name="palette" /> Variants</h2>

| Variant | Description | Recommended Context |
| :--- | :--- | :--- |
| `Primary` | Solid purple (`#4A2BC2`) | Main action on screen (e.g., Submit, Pay, Continue) |
| `Secondary` | Amber / Neutral tone | Alternative secondary options (e.g., Save Draft) |
| `Outline` | Transparent fill with border | Low-emphasis actions (e.g., Cancel, Back) |
| `Destructive` | Red error accent | Irreversible actions (e.g., Delete Account, Discard) |
| `Ghost` | Flat transparent button | Inline text actions |

---

<h2><MIcon name="settings" /> Parameters</h2>

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `text` | `String` | **Required** | The text displayed inside the button |
| `onClick` | `() -> Unit` | **Required** | Callback invoked when user clicks the button |
| `modifier` | `Modifier` | `Modifier` | Compose layout modifier |
| `variant` | `Ux4gButtonVariant` | `Primary` | Visual style variant |
| `size` | `Ux4gButtonSize` | `Medium` | Button size (`Small`, `Medium`, `Large`) |
| `enabled` | `Boolean` | `true` | Whether the button is interactive |
| `isLoading` | `Boolean` | `false` | Shows animated spinner and disables clicks |
| `leadingIcon` | `ImageVector?` | `null` | Optional icon rendered before the text |
| `trailingIcon` | `ImageVector?` | `null` | Optional icon rendered after the text |
