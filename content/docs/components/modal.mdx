<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Compose Example"
import androidx.compose.runtime.*
import com.ux4g.designsystemv1.components.Ux4gModal

@Composable
fun ConfirmationDialogExample() {
    var open by remember { mutableStateOf(false) }

    Ux4gModal(
        show = open,
        title = "Confirm Action",
        message = "Do you want to proceed with Aadhaar authentication?",
        confirmText = "Proceed",
        dismissText = "Cancel",
        onConfirm = { open = false },
        onDismiss = { open = false }
    )
}
```

<h2><MIcon name="settings" /> Parameters</h2>

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `show` <span className="text-red-500 font-bold">*</span> | `Boolean` | Controls whether the modal dialog is visible. | `—` |
| `title` <span className="text-red-500 font-bold">*</span> | `String` | Dialog headline title. | `—` |
| `message` <span className="text-red-500 font-bold">*</span> | `String` | Dialog explanation body copy. | `—` |
| `onConfirm` <span className="text-red-500 font-bold">*</span> | `() -> Unit` | Primary action button click callback. | `—` |
| `onDismiss` <span className="text-red-500 font-bold">*</span> | `() -> Unit` | Dismiss / cancel button click callback. | `—` |
| `confirmText` | `String` | Primary confirm button label. | `"Confirm"` |
| `dismissText` | `String` | Dismiss button label. | `"Cancel"` |
| `isDestructive` | `Boolean` | Styles confirm button in red destructive tone. | `false` |
| `icon` | `Ux4gIcon?` | Optional top center status visual icon. | `null` |
