# Draft Status & Status Banner (`Ux4gStatusBanner`)

The **UX4G Draft Status and Status Banner** components communicate live draft state, auto-save synchronization progress, and expiration countdown warnings during multi-step citizen application flows.

### Key Capabilities

- **Auto-Save Feedback**: Real-time feedback transitions across saving (`SavingLight` with loader), saved confirmation (`SuccessLight` with check icon), and idle states.
- **Expiration Alerts**: Timed warning banners for draft expiry (`WarningLight` with date pill, `WarningSolid` for imminent 24-hour urgency, and `ErrorLight` for expired drafts with recovery actions).
- **Application Draft Cards**: High-density expandable draft cards featuring stage step tags, timestamps, and quick action CTAs ("Resume", "Discard").
- **Banner Host Overlay**: Built-in animated floating banner host (`Ux4gBannerHost`) with auto-dismiss timers.

Import from:
```kotlin
import com.ux4g.designsystemv1.components.statusbanner.*
```

<h2><MIcon name="code" /> Complete Kotlin Implementation</h2>

### 1. Form Auto-Save State Controller

```kotlin title="FormAutoSaveBanner.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.CheckCircle
import androidx.compose.material3.Icon
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.statusbanner.*
import com.ux4g.designsystemv1.components.loader.Ux4gLoader
import com.ux4g.designsystemv1.foundation.Ux4gColors

enum class AutoSaveStatus {
    Idle,
    Saving,
    Saved,
    Error
}

@Composable
fun AutoSaveIndicator(status: AutoSaveStatus, lastSavedTime: String) {
    when (status) {
        AutoSaveStatus.Saving -> {
            Ux4gStatusBanner(
                variant = Ux4gBannerVariant.WarningLight,
                title = "Saving draft...",
                trailingIcon = {
                    Ux4gLoader(size = 16.dp, strokeWidth = 2.dp, color = Ux4gColors.primary)
                }
            )
        }
        AutoSaveStatus.Saved -> {
            Ux4gStatusBanner(
                variant = Ux4gBannerVariant.SuccessLight,
                title = "Draft saved successfully at $lastSavedTime",
                leadingIcon = {
                    Icon(Icons.Default.CheckCircle, contentDescription = null, tint = Ux4gColors.green600)
                }
            )
        }
        AutoSaveStatus.Error -> {
            Ux4gStatusBanner(
                variant = Ux4gBannerVariant.ErrorLight,
                title = "Failed to save draft. Check connection.",
                onDismiss = { /* retry or dismiss */ }
            )
        }
        AutoSaveStatus.Idle -> { /* hidden */ }
    }
}
```

### 2. Imminent Expiration Warning with Floating Banner Host

```kotlin title="DraftExpirationAlert.kt"
import androidx.compose.runtime.*
import com.ux4g.designsystemv1.components.statusbanner.*

@Composable
fun ApplicationScreenWithDraftAlert(bannerHostState: Ux4gBannerHostState) {
    LaunchedEffect(Unit) {
        bannerHostState.show(
            Ux4gBannerData(
                variant = Ux4gBannerVariant.WarningSolid,
                title = "Your draft expires tomorrow. Submit today",
                subtitle = "Incomplete forms are automatically purged after 15 days of inactivity.",
                autoDismiss = false
            )
        )
    }

    Ux4gBannerHost(hostState = bannerHostState)
}
```

### 3. `Ux4gBannerData` Data Model

Passed into `bannerHostState.show(Ux4gBannerData(...))` to display a dynamic overlay banner.

| Field | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `variant` <span className="text-red-500 font-bold">*</span> | `Ux4gBannerVariant` | Visual semantic tone (`WarningLight`, `WarningSolid`, `ErrorLight`, `SuccessLight`, etc.). | `—` |
| `title` <span className="text-red-500 font-bold">*</span> | `String` | Primary headline text for the floating banner. | `—` |
| `subtitle` | `String?` | Optional body description text providing further context. | `null` |
| `autoDismiss` | `Boolean` | When `true`, automatically dismisses the banner after `durationMillis`. | `false` |
| `durationMillis` | `Long` | Display duration before auto-dismissal when `autoDismiss = true`. | `4000L` |
| `onDismiss` | `(() -> Unit)?` | Callback triggered when the banner is dismissed or closed. | `null` |

### 4. `Ux4gBannerVariant` Reference Guide

| Variant | Background Color | Text / Icon Color | Context & Best Practice |
| :--- | :--- | :--- | :--- |
| `WarningLight` | Light Amber (`12% orange600`) | `neutral900` / `orange600` | Expiration countdowns, draft warnings, soft prerequisites |
| `WarningSolid` | Solid Orange (`orange600`) | White (`neutral0`) | Imminent deadline alerts, urgent 24h expiration warnings |
| `ErrorLight` | Light Red (`12% red600`) | `neutral900` / `red600` | Expired drafts, failed auto-save sync, validation blocks |
| `SuccessLight` | Light Green (`12% green600`) | `neutral900` / `green600` | Successful draft saved confirmations, upload sync success |
| `SavingLight` | Light Primary (`12% primary`) | `neutral900` / `primary` | Live background auto-save synchronization spinner |
| `InfoLight` | Light Blue (`12% blue600`) | `neutral900` / `blue600` | General guidelines, document checklist reminders |
| `NeutralLight` | Translucent Gray (`5% neutral900`) | `neutral900` | Non-urgent system notes, informational banners |
| `PrimaryLight` | Light Primary (`12% primary`) | `neutral900` / `primary` | Feature updates and account confirmations |
