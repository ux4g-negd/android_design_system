# Radio Button (`Ux4gRadioButton`)

The UX4G Radio Button component allows users to select a single option from a set of mutually exclusive choices. It is designed specifically for citizen-facing forms, survey questionnaires, payment gateway options, and administrative workflows.

### Key Capabilities

- **Generic & Boolean Overloads**: Type-safe `<T>` selection with `value` / `groupValue` binding or direct `selected` / `onClick` state control.
- **Validation & Status Variants**: Visual ring status and contextual description messaging (`Helper`, `Error`, `Warning`, `Success`) with automatic status icons.
- **Size Options**: Preconfigured sizes: `Small` (16dp), `Medium` (20dp), and `Large` (24dp).
- **Form Controls**: Support for required indicator asterisks (`*`), trailing icons, custom typography, disabled states, and centered touch ripples.

Import from `com.ux4g.designsystemv1.components.radiobutton.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

### 1. Type-Safe Radio Selection Group

```kotlin title="PaymentModeSelection.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.radiobutton.*

enum class PaymentMode(val title: String) {
    UPI("UPI / Instant Transfer"),
    NetBanking("Internet Banking"),
    DebitCard("Debit / Credit Card")
}

@Composable
fun PaymentSelectionSection() {
    var selectedMode by remember { mutableStateOf(PaymentMode.UPI) }

    Column(
        modifier = Modifier.padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        PaymentMode.values().forEach { mode ->
            Ux4gRadioButton(
                value = mode,
                groupValue = selectedMode,
                onValueChange = { selectedMode = it },
                label = mode.title,
                size = Ux4gRadioButtonSize.Medium
            )
        }
    }
}
```

### 2. Form Field with Required Asterisk & Validation

```kotlin title="DeclarationRadio.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.radiobutton.*

@Composable
fun CitizenshipDeclaration(
    isCitizen: Boolean?,
    onStatusChange: (Boolean) -> Unit,
    hasValidationError: Boolean
) {
    Column(
        modifier = Modifier.padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(10.dp)
    ) {
        Ux4gRadioButton(
            selected = isCitizen == true,
            onClick = { onStatusChange(true) },
            label = "I am an Indian Citizen",
            isRequired = true,
            size = Ux4gRadioButtonSize.Medium,
            description = if (hasValidationError && isCitizen == null) "Mandatory selection required" else null,
            descriptionVariant = if (hasValidationError && isCitizen == null) Ux4gRadioButtonDescriptionVariant.Error else Ux4gRadioButtonDescriptionVariant.Helper,
            status = if (hasValidationError && isCitizen == null) Ux4gRadioButtonStatus.Error else Ux4gRadioButtonStatus.DefaultStatus
        )

        Ux4gRadioButton(
            selected = isCitizen == false,
            onClick = { onStatusChange(false) },
            label = "I am a Foreign National / NRI",
            isRequired = true,
            size = Ux4gRadioButtonSize.Medium
        )
    }
}
```

### `Ux4gRadioButton<T>` (Generic Model)

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `value` <span className="text-red-500 font-bold">*</span> | `T` | The value represented by this individual radio button. | `—` |
| `groupValue` <span className="text-red-500 font-bold">*</span> | `T?` | The currently active selected value for the radio group. | `—` |
| `onValueChange` <span className="text-red-500 font-bold">*</span> | `(T) -> Unit` | Callback invoked when this radio option is selected. | `—` |
| `modifier` | `Modifier` | Compose layout modifier for outer container. | `Modifier` |

| `isRequired` | `Boolean` | Appends a red asterisk (`*`) next to the label when `true`. | `false` |
| `trailingIcon` | `Ux4gIcon?` | Optional UX4G icon placed inline beside the label text. | `null` |
| `trailingImageVector` | `ImageVector?` | Optional Compose `ImageVector` placed beside the label text. | `null` |

| `status` | `Ux4gRadioButtonStatus` | Outer ring visual state coloring (`DefaultStatus`, `Error`, `Warning`, `Success`). | `Ux4gRadioButtonStatus.DefaultStatus` |
| `color` | `Color?` | Custom tint color for selected circle ring. Takes precedence over `status`. | `null` |

| `labelStyle` | `TextStyle?` | Custom typography style override for the label text. | `null` |
