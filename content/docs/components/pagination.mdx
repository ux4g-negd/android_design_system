# Pagination (`Ux4gPaginationDotted`)

The UX4G Pagination component provides animated dot progression indicators for multi-page carousels, onboarding walkthroughs, and large list views.

It supports:
- **Smooth Animation**: Active page dot seamlessly expands into an elongated pill (`size.dotSize * 2.5f`).
- **Container Styling**: Default borderless indicator or rounded `Capsule` container pill.
- **Arrow Alignments**: Inline bilateral navigation chevrons (`<` ... dots ... `>`), chevron-free mode, or right-grouped arrow controls.
- **Sizes**: `Small` (10dp dot, 24dp arrow) and `Medium` (12dp dot, 32dp arrow).

Import from `com.ux4g.designsystemv1.components.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Citizen Scheme Carousel Pagination Example"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.Ux4gPaginationDotted
import com.ux4g.designsystemv1.components.Ux4gPaginationSize
import com.ux4g.designsystemv1.components.Ux4gPaginationVariant

@Composable
fun SchemeCarouselPaginationExample() {
    var activePage by remember { mutableStateOf(0) }
    val pageCount = 5

    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.spacedBy(20.dp)
    ) {
        // Standard Dotted Indicator
        Ux4gPaginationDotted(
            totalPageCount = pageCount,
            currentPageIndex = activePage,
            onPageChange = { activePage = it },
            variant = Ux4gPaginationVariant.Default,
            size = Ux4gPaginationSize.Small
        )

        // Capsule Indicator with Right-Aligned Controls
        Ux4gPaginationDotted(
            totalPageCount = pageCount,
            currentPageIndex = activePage,
            onPageChange = { activePage = it },
            arrowsOnRight = true,
            variant = Ux4gPaginationVariant.Capsule,
            size = Ux4gPaginationSize.Medium
        )
    }
}
```

<h2><MIcon name="settings" /> Parameters</h2>

### `Ux4gPaginationDotted` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `totalPageCount` <span className="text-red-500 font-bold">*</span> | `Int` | Total number of pages / steps in the progression sequence. | — |
| `currentPageIndex` <span className="text-red-500 font-bold">*</span> | `Int` | Zero-based index of the currently active page. | — |
| `onPageChange` <span className="text-red-500 font-bold">*</span> | `(Int) -> Unit` | Callback invoked when a user clicks a dot or navigation arrow button. | — |
| `modifier` | `Modifier` | Compose layout modifier applied to outer container. | `Modifier` |
| `showArrows` | `Boolean` | Controls whether previous and next arrow buttons are displayed. | `true` |
| `arrowsOnRight` | `Boolean` | When true, groups navigation chevrons together on the right side. | `false` |
| `variant` | `Ux4gPaginationVariant` | Visual style of the indicator: `Default` or `Capsule`. | `Ux4gPaginationVariant.Default` |
| `size` | `Ux4gPaginationSize` | Size preset: `Small` (10dp dot, 24dp arrow) or `Medium` (12dp dot, 32dp arrow). | `Ux4gPaginationSize.Small` |
| `enabled` | `Boolean` | Interactive state for dot clicks and chevron triggers. | `true` |
| `activeColor` | `Color?` | Background color of the active elongated pill dot. | `Ux4gColors.primary` |
| `inactiveColor` | `Color?` | Background color of inactive dots and circular arrow buttons. | `Ux4gColors.primary100` |
| `inactiveBorderColor` | `Color?` | Optional border color for inactive dots. | `Color.Transparent` |
| `width` | `Dp?` | Optional explicit fixed width constraint. | `null` |
| `height` | `Dp?` | Optional explicit fixed height constraint. | `null` |
