<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Compose Example"
import androidx.compose.runtime.*
import com.ux4g.designsystemv1.components.Ux4gPaginationIndicator

@Composable
fun PaginationExample() {
    var page by remember { mutableStateOf(1) }

    Ux4gPaginationIndicator(
        currentPage = page,
        totalPages = 10,
        onPageChange = { page = it }
    )
}
```

<h2><MIcon name="settings" /> Parameters</h2>

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `currentPage` <span className="text-red-500 font-bold">*</span> | `Int` | Active 1-indexed page pointer. | `—` |
| `totalPages` <span className="text-red-500 font-bold">*</span> | `Int` | Total number of pages available. | `—` |
| `onPageChange` <span className="text-red-500 font-bold">*</span> | `(Int) -> Unit` | Callback triggered when page button is clicked. | `—` |
| `modifier` | `Modifier` | Compose layout modifier. | `Modifier` |
| `maxVisiblePages` | `Int` | Maximum visible number buttons before ellipsis. | `5` |
