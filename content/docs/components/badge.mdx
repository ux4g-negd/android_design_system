# Badge (`Ux4gBadge`)

Badges highlight new information, status alerts, or numerical counters (e.g. `9+`, `99+`) on avatars, buttons, or standalone cards.

Import from `com.ux4g.designsystemv1.components.Ux4gBadge`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Compose Example"
import com.ux4g.designsystemv1.components.Ux4gBadge
import com.ux4g.designsystemv1.components.Ux4gBadgeLimit
import com.ux4g.designsystemv1.components.Ux4gBadgeVariant

// 1. Standalone Status Badge
Ux4gBadge(
    text = "Under Review",
    variant = Ux4gBadgeVariant.Warning
)

// 2. Numeric Count Badge with limit
Ux4gBadge(
    count = 120,
    limit = Ux4gBadgeLimit.DoubleDigit // Displays "99+"
)
```

---

<h2><MIcon name="settings" /> Parameters</h2>

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `text` | `String?` | `null` | Label text for text badges |
| `count` | `Int?` | `null` | Integer counter for numeric badges |
| `limit` | `Ux4gBadgeLimit` | `DoubleDigit` | Caps display count (`SingleDigit` -> `9+`, `DoubleDigit` -> `99+`) |
| `variant` | `Ux4gBadgeVariant` | `Primary` | Semantic style (`Primary`, `Success`, `Warning`, `Error`, `Info`, `Neutral`) |
| `isDot` | `Boolean` | `false` | When true, renders a compact indicator dot |
