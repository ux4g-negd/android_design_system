# Tag (`Ux4gTag` / `Ux4gUnifiedPillTag`)

The UX4G Tag component renders compact metadata pills and status indicators. It helps citizens and administrators quickly identify document classifications, application states, priority flags, and multi-part status summaries across government portals.

### Key Capabilities

- **Semantic Color Schemes**: 6 purpose-built color themes (`Neutral`, `Brand`, `Success`, `Warning`, `Error`, `Info`).
- **Visual Styles**: `Tonal` (tinted background), `Filled` (solid high-contrast background), `Outline` (bordered), and `Text` (minimal plain text).
- **Shapes & Sizes**: `Circular` (pill shape, 999dp radius) and `Rectangular` (rounded rectangular, 4dp radius); `M` (20dp height) and `L` (24dp height).
- **Unified Multi-Segment Pill Tag**: `Ux4gUnifiedPillTag` combining multiple `Ux4gPillSegment` entries separated by clean vertical dividers inside a single cohesive container (e.g., `"2 days remaining | Pending"`).
- **Leading Content & Dismiss Slot**: Support for leading icons, avatar initials, or status dots, plus optional `onDismiss` close action button.
- **Custom Styling**: Complete custom overrides for background color, content color, border stroke, typography, and corner radius.

Import from `com.ux4g.designsystemv1.components.tag.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

### 1. Document Classification & Verification Status

```kotlin title="DocumentStatusTags.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.tag.*
import com.ux4g.designsystemv1.foundation.Ux4gColors
import com.ux4g.designsystemv1.foundation.Ux4gIconComponent
import com.ux4g.designsystemv1.foundation.Ux4gIcons

@Composable
fun DocumentStatusTagExample() {
    var isDismissed by remember { mutableStateOf(false) }

    Row(
        horizontalArrangement = Arrangement.spacedBy(8.dp),
        modifier = Modifier.padding(16.dp)
    ) {
        // Tonal Scheme Pill Tag with Leading Icon
        Ux4gTag(
            text = "Central Sector Scheme",
            colorScheme = Ux4gTagColor.Brand,
            style = Ux4gTagStyle.Tonal,
            size = Ux4gTagSize.M,
            leadingContent = {
                Ux4gIconComponent(
                    icon = Ux4gIcons.Home,
                    contentDescription = "Scheme",
                    modifier = Modifier.size(12.dp),
                    tint = Ux4gColors.primary
                )
            }
        )

        // Rectangular Outline Status Tag
        Ux4gTag(
            text = "Verified",
            colorScheme = Ux4gTagColor.Success,
            shape = Ux4gTagShape.Rectangular,
            style = Ux4gTagStyle.Outline,
            size = Ux4gTagSize.M
        )

        // Dismissible Filter Tag
        if (!isDismissed) {
            Ux4gTag(
                text = "State: Maharashtra",
                colorScheme = Ux4gTagColor.Neutral,
                style = Ux4gTagStyle.Tonal,
                size = Ux4gTagSize.M,
                onDismiss = { isDismissed = true }
            )
        }
    }
}
```

### 2. Unified Multi-Segment Tracking Pill

```kotlin title="ApplicationTrackingTag.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.Composable
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.tag.*

@Composable
fun ApplicationTrackingBadge() {
    Ux4gUnifiedPillTag(
        segments = listOf(
            Ux4gPillSegment(
                text = "2 days remaining",
                bold = false
            ),
            Ux4gPillSegment(
                text = "Pending",
                textColor = Color(0xFFFA8C16), // Warning Orange
                bold = true
            )
        ),
        size = Ux4gTagSize.L,
        backgroundColor = Color(0xFFFFFFFF),
        borderColor = Color(0xFFE5E7EB),
        dividerColor = Color(0xFFE5E7EB)
    )
}
```

### `Ux4gTag` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `text` <span className="text-red-500 font-bold">*</span> | `String` | Label text displayed inside the tag container. | `—` |
| `modifier` | `Modifier` | Compose modifier applied to the outer tag container. | `Modifier` |
| `size` | `Ux4gTagSize` | Tag height and padding size (`M` = 20dp, `L` = 24dp). | `Ux4gTagSize.M` |
| `shape` | `Ux4gTagShape` | Tag corner geometry (`Circular` = 999dp pill, `Rectangular` = 4dp). | `Ux4gTagShape.Circular` |
| `style` | `Ux4gTagStyle` | Fill style variant (`Tonal`, `Filled`, `Outline`, `Text`). | `Ux4gTagStyle.Tonal` |
| `colorScheme` | `Ux4gTagColor` | Predefined semantic color theme (`Neutral`, `Brand`, `Success`, `Warning`, `Error`, `Info`). | `Ux4gTagColor.Neutral` |
| `leadingContent` | `(@Composable () -> Unit)?` | Optional leading composable slot for icons, avatars, or status indicators. | `null` |
| `onDismiss` | `(() -> Unit)?` | Optional callback rendering a trailing close icon button for removable tags. | `null` |
| `customBackgroundColor` | `Color?` | Custom background color override. | `null` |
| `customContentColor` | `Color?` | Custom text and icon tint color override. | `null` |
| `customBorderColor` | `Color?` | Custom border stroke color override. | `null` |
| `customBorderWidth` | `Dp?` | Custom border stroke width override. | `null` |
| `customTextStyle` | `TextStyle?` | Custom typography style override. | `null` |
| `customCornerRadius` | `Dp?` | Custom corner radius value override. | `null` |

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `segments` <span className="text-red-500 font-bold">*</span> | `List<Ux4gPillSegment>` | List of text/icon segments displayed sequentially with integrated dividers. | `—` |

| `borderColor` | `Color?` | Outer border stroke color. | `null` |
| `borderWidth` | `Dp` | Outer border stroke width. | `1.dp` |
| `dividerColor` | `Color?` | Color of vertical dividers placed between segments. | `null` |
