<h2><MIcon name="code" /> 1. Standard Input Field (`Ux4gInputField`)</h2>

```kotlin title="Compose Example"
import com.ux4g.designsystemv1.components.inputfield.Ux4gInputField
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember

var name by remember { mutableStateOf("") }

Ux4gInputField(
    value = name,
    onValueChange = { name = it },
    label = "Full Name",
    placeholder = "Enter your name as per Aadhaar",
    isRequired = true,
    helperText = "Must match official government records"
)
```

<h2><MIcon name="flag" /> 2. Aadhaar Input Field (<code>Ux4gAadhaarInputField</code>)</h2>

Specialized 12-digit formatter that automatically formats input into `XXXX XXXX XXXX` chunks with official Verhoeff algorithm verification and mask toggling.

```kotlin title="Aadhaar Example"
import com.ux4g.designsystemv1.components.inputfield.Ux4gAadhaarInputField

var aadhaar by remember { mutableStateOf("") }
var isValid by remember { mutableStateOf(false) }

Ux4gAadhaarInputField(
    value = aadhaar,
    onValueChange = { aadhaar = it },
    onValidationChange = { isValid = it },
    label = "Aadhaar Number",
    isRequired = true,
    allowMaskToggle = true
)
```

