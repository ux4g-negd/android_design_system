# Input Field (`Ux4gInputField`)

The UX4G Input Field component family provides high-accessibility text entry controls with comprehensive support for validation states, password toggles, affixes, leading/trailing icons, read-only mode, and specialized Indian citizen identity inputs (Aadhaar & PAN).

Import from `com.ux4g.designsystemv1.components.inputfield.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Citizen Registration Form Example"
import androidx.compose.foundation.layout.*
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Badge
import androidx.compose.material.icons.filled.CreditCard
import androidx.compose.material.icons.filled.Lock
import androidx.compose.material.icons.filled.Person
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.inputfield.*

@Composable
fun CitizenFormExample() {
    var fullName by remember { mutableStateOf("") }
    var password by remember { mutableStateOf("") }
    var aadhaar by remember { mutableStateOf("") }
    var pan by remember { mutableStateOf("") }
    var monthlyIncome by remember { mutableStateOf("") }

    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        // 1. Text Field with Leading Icon
        Ux4gInputField(
            value = fullName,
            onValueChange = { fullName = it },
            label = "Full Name",
            required = true,
            placeholder = "Enter your full name",
            leadingIcon = Icons.Default.Person
        )

        // 2. Password Field
        Ux4gInputField(
            value = password,
            onValueChange = { password = it },
            label = "Account Password",
            required = true,
            placeholder = "Enter password",
            type = Ux4gInputFieldType.Password,
            leadingIcon = Icons.Default.Lock,
            showPasswordToggle = true
        )

        // 3. Aadhaar Auto-formatting (XXXX XXXX XXXX) with Verhoeff Validation
        Ux4gAadhaarInputField(
            value = aadhaar,
            onValueChange = { aadhaar = it },
            label = "Aadhaar Number",
            required = true,
            leadingIcon = Icons.Default.Badge
        )

        // 4. PAN Card Auto-uppercase & Regex Validation
        Ux4gPanInputField(
            value = pan,
            onValueChange = { pan = it },
            label = "PAN Card Number",
            required = true,
            leadingIcon = Icons.Default.CreditCard
        )

        // 5. Income with Currency Prefix
        Ux4gInputField(
            value = monthlyIncome,
            onValueChange = { monthlyIncome = it },
            label = "Monthly Income",
            placeholder = "0",
            prefixText = "₹",
            postfixText = ".00",
            type = Ux4gInputFieldType.Number
        )
    }
}
```

### 1. `Ux4gInputField` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `value` <span className="text-red-500 font-bold">*</span> | `String` | Current text value of the input field. | — |
| `onValueChange` <span className="text-red-500 font-bold">*</span> | `(String) -> Unit` | Callback invoked when citizen types or modifies content. | — |
| `modifier` | `Modifier` | Compose layout modifier applied to the outer container. | `Modifier` |
| `size` | `Ux4gInputFieldSize` | Container height variant: `Small` (32dp), `Medium` (40dp), `Large` (48dp), `XL` (56dp). | `Ux4gInputFieldSize.Medium` |
| `type` | `Ux4gInputFieldType` | Input type & keyboard configuration: `Text`, `Password`, `Number`, `Email`. | `Ux4gInputFieldType.Text` |
| `status` | `Ux4gInputFieldStatus` | Validation visual state: `Default`, `Success`, `Warning`, `Error`. | `Ux4gInputFieldStatus.Default` |
| `label` | `String?` | Header title label displayed above the field. | `null` |
| `required` | `Boolean` | When true, renders a red asterisk (`*`) next to the label. | `false` |
| `placeholder` | `String?` | Placeholder text shown when the input field is empty. | `null` |
| `caption` | `String?` | Explanatory helper or error description text below the input field. | `null` |
| `leadingIcon` | `Any?` | Icon placed at the start (`ImageVector`, `Ux4gIcon`, or drawable resource Int). | `null` |
| `trailingIcon` | `Any?` | Icon placed at the end (`ImageVector`, `Ux4gIcon`, or drawable resource Int). | `null` |
| `onTrailingIconPressed` | `(() -> Unit)?` | Optional click callback for the trailing icon. | `null` |
| `prefixText` | `String?` | Static affix text anchored before the editable text (e.g. `"₹"` or `"https://"`). | `null` |
| `postfixText` | `String?` | Static affix text anchored after the editable text (e.g. `".00"` or `".com"`). | `null` |
| `trailingIconLabel` | `Any?` | Optional info icon rendered adjacent to the label. | `null` |
| `enabled` | `Boolean` | Controls interactive enabled state and disabled styling. | `true` |
| `readOnly` | `Boolean` | When true, text cannot be edited but remains focusable and copyable. | `false` |
| `singleLine` | `Boolean` | Whether input is single-line or expandable multiline. | `true` |
| `maxLines` | `Int` | Maximum lines allowed before vertical scrolling. | `1` |
| `maxLength` | `Int?` | Maximum character length limit. | `null` |
| `textAlign` | `TextAlign` | Text alignment within the input area. | `TextAlign.Start` |
| `showPasswordToggle` | `Boolean` | When type is `Password`, controls rendering of the eye visibility toggle. | `true` |
| `style` | `TextStyle?` | Custom text style override for the typed text. | `null` |
| `placeholderStyle` | `TextStyle?` | Custom text style override for placeholder. | `null` |
| `labelStyle` | `TextStyle?` | Custom text style override for label. | `null` |
| `captionStyle` | `TextStyle?` | Custom text style override for caption. | `null` |
| `backgroundColor` | `Color?` | Custom container background color override. | `null` |
| `borderColor` | `Color?` | Custom border color override. | `null` |
| `borderWidth` | `Dp` | Custom border width. | `1.dp` |
| `keyboardOptions` | `KeyboardOptions?` | Custom software keyboard options. | `null` |
| `keyboardActions` | `KeyboardActions` | Custom software keyboard actions (Done, Next, Search). | `KeyboardActions.Default` |
