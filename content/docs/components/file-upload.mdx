# File Upload (`Ux4gFileUpload`)

The UX4G File Upload component provides an intuitive document attachment dropzone and file management interface for uploading application forms, identity proofs, certificates, and attachments across citizen portals and mobile workflows.

### Key Capabilities

- **Dual Interaction Modes**: Support for standard file browsing (`Upload`) and camera-based document capture (`Scan`).
- **File Validation**: Built-in enforcement for permitted file extensions (`PDF`, `JPG`, `PNG`) and maximum file size thresholds (e.g. `5 MB`).
- **Status & Progress Indicators**: Real-time visual feedback for in-progress uploads with percentage tracking, verified uploads with success badges, and failed uploads with retry actions.
- **Dynamic List Management**: Seamless handling of single and multi-file attachments with one-tap removal and dynamic "Add More files" actions.

Import from `com.ux4g.designsystemv1.components.fileupload.*`.

### 2. Managing Multiple Uploaded Attachments

```kotlin title="MultiDocumentAttachment.kt"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.fileupload.Ux4gFileUpload
import com.ux4g.designsystemv1.components.fileupload.Ux4gUploadedFile
import com.ux4g.designsystemv1.components.fileupload.Ux4gFileType
import com.ux4g.designsystemv1.components.fileupload.Ux4gUploadStatus

@Composable
fun MultiDocumentAttachment() {
    var fileList by remember {
        mutableStateOf(
            listOf(
                Ux4gUploadedFile(
                    fileName = "Document_name.pdf",
                    description = "Description",
                    fileType = Ux4gFileType.PDF,
                    status = Ux4gUploadStatus.Success
                )
            )
        )
    }

    Ux4gFileUpload(
        title = "Upload or scan document",
        allowedExtensions = listOf("PDF", "JPG", "PNG"),
        maxSizeMb = 5,
        uploadedFiles = fileList,
        onUploadClick = {
            // Pick and attach additional documents
        },
        onScanClick = {
            // Add more files via camera scan
        },
        onRemoveFile = { removedFile ->
            fileList = fileList.filter { it != removedFile }
        },
        modifier = Modifier.fillMaxWidth().padding(16.dp)
    )
}
```

<h2><MIcon name="settings" /> Parameters</h2>

| Parameter | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `title` <span className="text-red-500 font-bold">*</span> | `String` | Header title displayed inside the upload zone. | `"Upload or scan document"` |
| `allowedExtensions` | `List<String>` | Permitted file format extensions. | `listOf("PDF", "JPG", "PNG")` |
| `maxSizeMb` | `Int` | Maximum allowable file size per attachment in MB. | `5` |
| `uploadedFiles` | `List<Ux4gUploadedFile>` | List of currently attached documents with their statuses. | `emptyList()` |
| `onUploadClick` | `() -> Unit` | Callback triggered when the Upload button is pressed. | `{}` |
| `onScanClick` | `() -> Unit` | Callback triggered when the Scan / Add More button is pressed. | `{}` |
| `onRemoveFile` | `((Ux4gUploadedFile) -> Unit)?` | Callback triggered when the remove (X) button is pressed on a file item. | `null` |
| `onRetryFile` | `((Ux4gUploadedFile) -> Unit)?` | Callback triggered when the retry link is clicked on a failed file item. | `null` |
| `enabled` | `Boolean` | Controls interactive enabled state of the dropzone. | `true` |
| `modifier` | `Modifier` | Compose layout modifier applied to the container. | `Modifier` |
