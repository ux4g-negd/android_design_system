# Chips Suite (`Ux4gChips`)

The UX4G Chips suite provides compact interactive elements for selection, filtering, dynamic tag inputs, and categorical tagging:
1. **Choice Chip (`Ux4gChoiceChip`)**: Single or multiple select chips with solid primary active fill, icons, and custom colors.
2. **Filter Chip (`Ux4gFilterChip`)**: Subtle filter toggles with soft 8% primary tint and primary text on selection.
3. **Input Chip (`Ux4gInputChip`)**: Removable tag chips with leading avatar/icon and a trailing dismiss (`✕`) button in `XS`, `S`, `M` sizes.
4. **Input Chip Field (`Ux4gInputChipField`)**: Comprehensive text or dropdown input container allowing citizens to add and manage dynamic chips.
5. **Chip Group (`Ux4gChipGroup`)**: Layout container supporting horizontal scroll or wrapping multi-line flow layouts.

Import from `com.ux4g.designsystemv1.components.chips.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Chips Showcase Example"
import androidx.compose.foundation.layout.*
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Check
import androidx.compose.material.icons.filled.Person
import androidx.compose.material.icons.filled.Star
import androidx.compose.material3.Icon
import androidx.compose.material3.Text
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.chips.*
import com.ux4g.designsystemv1.foundation.Ux4gColors
import com.ux4g.designsystemv1.foundation.defaultTypography

@Composable
fun ChipsShowcaseScreen() {
    Column(
        modifier = Modifier.padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(20.dp)
    ) {
        // 1. Choice Chips
        Text("Choice Chips", style = defaultTypography.hS_default)
        Row(horizontalArrangement = Arrangement.spacedBy(8.dp)) {
            var choice1 by remember { mutableStateOf(true) }
            Ux4gChoiceChip(
                text = "Selected",
                selected = choice1,
                onClick = { choice1 = !choice1 },
                leadingContent = {
                    Icon(Icons.Default.Check, null, Modifier.size(16.dp), tint = Ux4gColors.neutral50)
                }
            )
            Ux4gChoiceChip(text = "Unselected", selected = false, onClick = {})
            Ux4gChoiceChip(
                text = "Small",
                selected = true,
                size = Ux4gChoiceChipSize.S,
                onClick = {},
                trailingContent = {
                    Icon(Icons.Default.Star, null, Modifier.size(12.dp), tint = Ux4gColors.neutral50)
                }
            )
        }

        // 2. Filter Chips
        Text("Filter Chips", style = defaultTypography.hS_default)
        Row(horizontalArrangement = Arrangement.spacedBy(8.dp)) {
            var filter1 by remember { mutableStateOf(true) }
            Ux4gFilterChip(text = "Selected", selected = filter1, onClick = { filter1 = !filter1 })
            Ux4gFilterChip(text = "Unselected", selected = false, onClick = {})
            Ux4gFilterChip(text = "Small Filter", selected = true, size = Ux4gFilterChipSize.S, onClick = {})
        }

        // 3. Input Chips
        Text("Input Chips", style = defaultTypography.hS_default)
        Row(horizontalArrangement = Arrangement.spacedBy(8.dp)) {
            Ux4gInputChip(
                text = "Medium",
                onDismiss = {},
                leadingContent = {
                    Icon(Icons.Default.Person, null, Modifier.size(16.dp), tint = Ux4gColors.neutral700)
                }
            )
            Ux4gInputChip(text = "Small", onDismiss = {}, size = Ux4gInputChipSize.S)
            Ux4gInputChip(text = "XS Chip", onDismiss = {}, size = Ux4gInputChipSize.XS)
        }

        // 4. Input Chip Field
        Text("Input Chip Field", style = defaultTypography.hS_default)
        var inputVal by remember { mutableStateOf("") }
        val tags = remember { mutableStateListOf("Aadhaar", "PAN Card", "Voter ID") }
        Ux4gInputChipField(
            value = inputVal,
            onValueChange = { inputVal = it },
            placeholder = "Add required document...",
            onAddChip = { tags.add(it) },
            chips = tags.map { tag ->
                { Ux4gInputChip(text = tag, onDismiss = { tags.remove(tag) }) }
            }
        )
    }
}
```

### Token & Enum Tables

#### `Ux4gChoiceChipSize` & `Ux4gFilterChipSize`

| Size Token | Choice Chip Padding | Filter Chip Height & Padding | Typography |
| :--- | :--- | :--- | :--- |
| `S` (Small) | Horizontal: 12dp, Vertical: 6dp | Height: 28dp, Horizontal: 12dp | Label Medium (`12.sp`) |
| `M` (Medium) | Horizontal: 16dp, Vertical: 8dp | Height: 32dp, Horizontal: 16dp | Label Large (`14.sp`) |

#### `Ux4gInputChipSize`

| Size Token | Container Height | Horizontal Padding | Icon Size | Typography |
| :--- | :--- | :--- | :--- | :--- |
| `XS` | `20.dp` | `8.dp` | `12.dp` | Label Small (`11.sp`) |
| `S` | `28.dp` | `12.dp` | `16.dp` | Label Medium (`12.sp`) |
| `M` | `32.dp` | `16.dp` | `16.dp` | Label Large (`14.sp`) |

#### `Ux4gChipGroupArrangement`

| Value | Behavior |
| :--- | :--- |
| `Horizontal` | Single-line horizontally-scrollable row (`Row` + `horizontalScroll`). |
| `Wrap` | Multi-line wrapping layout (`FlowRow` with vertical `runSpacing`). |
