# Side Menu & Navigation Drawer (`Ux4gSideMenu` / `Ux4gDrawer`)

The UX4G Side Menu (Navigation Drawer) is an edge-docked sliding navigation surface that provides hierarchical destination routing for complex Indian public digital services, officer workflows, and citizen self-service portals.

Built strictly to UX4G design tokens, it features physics-based slide animation, drag gesture dismissal, Android system back-press handling, customizable header styles, search-as-you-type filtering, expandable accordion sub-menus, and action banner cards.

### Key Capabilities

- **5 Standard Preset Templates (`Ux4gSideMenuPresets`)**:
  - `Standard`: Government branding header with national emblem, portal title, search bar, and structured navigation sections.
  - `OfficerInbox`: Administrative workflow drawer featuring officer profile, unread inbox count badges, and review folders.
  - `CitizenProfile`: Prominent citizen profile summary card with status tags, account shortcuts, and "View profile" CTA.
  - `DepartmentSwitcher`: Multi-department selection menu with distinct department cards and access request shortcuts.
  - `ActionRequired`: Priority-focused drawer with alert cards (e.g., Aadhaar e-KYC verification) and nested application workflows.
- **Physics-Based Sliding Animation & Gestures**: Smooth left-to-right drawer movement with animated scrim fade, tap-to-dismiss, and physical back gesture support via `Ux4gSideMenuModal`.
- **Flexible Header Variations (`Ux4gSideMenuHeaderType`)**:
  - `Standard`: Government emblem/logo with official department title and subtitle.
  - `CompactUser`: User initials avatar, name, and email/department subtitle.
  - `ProminentUser`: Elevated profile card with role, verified badge, and quick action button.
  - `Plain`: Minimal clean title, subtitle, and close button.
  - `None`: Completely custom header or no header.
- **Accordion Sub-Navigation**: Nested items support expandable and collapsible groups (`defaultExpanded = true`).
- **Interactive Search Filter**: Built-in search field with automatic real-time filtering of navigation items.
- **Cross-Framework Parity**: Includes `Ux4gDrawer` as a direct alias for `Ux4gSideMenu` matching Flutter design system conventions.

Import from `com.ux4g.designsystemv1.components.*`.

## Complete Implementation Example

The following Jetpack Compose snippet demonstrates a complete citizen portal screen integrating `Ux4gSideMenuModal` with an app bar hamburger icon, physics slide animation, and scrim dismiss:

```kotlin
package com.example.app.ui

import androidx.compose.foundation.layout.*
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Menu
import androidx.compose.material.icons.outlined.*
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.*
import com.ux4g.designsystemv1.foundation.Ux4gColors
import com.ux4g.designsystemv1.theme.Ux4gTheme

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun CitizenPortalWithDrawerScreen() {
    var isDrawerOpen by remember { mutableStateOf(false) }
    var selectedDestination by remember { mutableStateOf("dashboard") }

    Scaffold(
        topBar = {
            TopAppBar(
                title = { Text("Revenue Department", style = Ux4gTheme.typography.hM_strong) },
                navigationIcon = {
                    IconButton(onClick = { isDrawerOpen = true }) {
                        Icon(
                            imageVector = Icons.Filled.Menu,
                            contentDescription = "Open navigation menu",
                            tint = Ux4gTheme.colorScheme.primary
                        )
                    }
                }
            )
        }
    ) { innerPadding ->
        Box(
            modifier = Modifier
                .fillMaxSize()
                .padding(innerPadding)
                .padding(16.dp)
        ) {
            Text(
                text = "Active Screen: \$selectedDestination",
                style = Ux4gTheme.typography.hL_strong
            )
        }

        // Modal Slide-Out Drawer with physics animation & scrim
        Ux4gSideMenuModal(
            isOpen = isDrawerOpen,
            onDismissRequest = { isDrawerOpen = false },
            headerType = Ux4gSideMenuHeaderType.Standard,
            title = "Revenue Department",
            subtitle = "Government of India",
            selectedKey = selectedDestination,
            onItemSelected = { item ->
                selectedDestination = item.key ?: item.label
                isDrawerOpen = false
            },
            actionCard = Ux4gSideMenuActionCard(
                title = "Verify your Aadhaar",
                description = "Complete identity verification to access all digital services.",
                buttonText = "Verify now",
                onButtonPressed = {
                    isDrawerOpen = false
                    // Start Aadhaar verification flow
                }
            ),
            bottomBranding = Ux4gSideMenuBottomBranding(
                title = "Digital India Initiative",
                subtitle = "Empowering citizens"
            ),
            showSignOut = true,
            onSignOut = {
                isDrawerOpen = false
                // Handle citizen logout
            }
        )
    }
}
```

| `subtitle` | `String?` | Secondary subtitle or government affiliation. | `"Government of India"` |
| `logo` | `(@Composable () -> Unit)?` | Custom leading composable slot for department emblem or seal. | `null` |
| `avatarInitials` | `String?` | 2-letter initials for user/department avatar (e.g. `"RK"`). | `null` |
| `avatarColor` | `Color?` | Background fill color of the avatar. | `null` |
| `userMetaText` | `String?` | Supporting metadata in `ProminentUser` header (e.g. `"12 applications"`). | `null` |
| `userActionButtonText` | `String?` | Action button label in `ProminentUser` header. | `"View profile"` |

| `showSearch` | `Boolean` | Whether to render the search input bar. | `true` |
| `searchPlaceholder` | `String` | Placeholder text inside search bar. | `"Search for..."` |
| `searchQuery` | `String?` | External controlled search query string. | `null` |
| `onSearchChanged` | `((String) -> Unit)?` | Callback fired when search query changes. | `null` |
| `autoFilterOnSearch` | `Boolean` | Automatically filters sections and items based on search input. | `true` |
| `sections` | `List<Ux4gSideMenuSection>?` | List of navigation sections containing navigation items. | `null` (uses default sections) |
| `items` | `List<Ux4gSideMenuItem>?` | Flat list of navigation items (wrapped in single section automatically). | `null` |
| `selectedKey` | `String?` | Key of the currently active navigation item. | `null` |
| `defaultSelectedKey` | `String?` | Initial selected key when uncontrolled. | `"dashboard"` |
| `onItemSelected` | `((Ux4gSideMenuItem) -> Unit)?` | Callback triggered when a navigation item is tapped. | `null` |
| `actionCard` | `Ux4gSideMenuActionCard?` | Configuration for embedded priority banner card. | `null` |
| `footerItems` | `List<Ux4gSideMenuItem>?` | Secondary utility items placed in the footer row. | `null` |
| `showSignOut` | `Boolean` | Whether to display the "Sign out" action item at bottom. | `true` |
| `signOutLabel` | `String` | Label text for sign out action item. | `"Sign out"` |
| `onSignOut` | `(() -> Unit)?` | Click listener callback for sign out action. | `null` |
| `bottomBranding` | `Ux4gSideMenuBottomBranding?` | Official branding block displayed at bottom of drawer. | `null` |
| `backgroundColor` | `Color?` | Surface background color of the drawer. | `null` (theme surface) |
| `elevation` | `Dp` | Drop shadow elevation depth. | `16.dp` |

### Enums & Types

#### `Ux4gSideMenuHeaderType`

| Value | Description |
| :--- | :--- |
| `Standard` | Official government emblem, department title, and subtitle. |
| `CompactUser` | User avatar initials, citizen/officer name, and email or division subtitle. |
| `ProminentUser` | Full profile summary card with role tag, application stats, and "View profile" button. |
| `Plain` | Clean title, subtitle, and close button without avatars or emblems. |
| `None` | Omits the header block entirely. |

#### `Ux4gSideMenuPosition`

| Value | Description |
| :--- | :--- |
| `Left` | Drawer is docked at the left edge and slides in from the left. |
| `Right` | Drawer is docked at the right edge and slides in from the right. |
