# Avatar Suite (`avatar_component`)

The UX4G Avatar suite provides 4 modular composable components for citizen profiles, verification badges, status indicators, and collaborative team stacks:
1. **Basic Avatar (`Ux4gAvatar`)**: Standard profile picture, initials, or icon fallback.
2. **Profile Avatar (`Ux4gProfileAvatar`)**: Base avatar with bottom-right verification badges or interactive action buttons.
3. **Avatar Group (`Ux4gAvatarGroup`)**: Stacked overlapping or spaced avatar group with automatic `+N` overflow limit counters.
4. **Status Avatar (`Ux4gStatusAvatar`)**: Online, offline, busy, and warning presence indicators.

Import from `com.ux4g.designsystemv1.components.avatar_component.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Avatar Showcase Example"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.avatar_component.Ux4gAvatar
import com.ux4g.designsystemv1.components.avatar_component.Ux4gProfileAvatar
import com.ux4g.designsystemv1.components.avatar_component.Ux4gProfileAvatarVariant
import com.ux4g.designsystemv1.components.avatar_component.Ux4gAvatarGroup
import com.ux4g.designsystemv1.components.avatar_component.Ux4gAvatarGroupItem
import com.ux4g.designsystemv1.components.avatar_component.Ux4gStatusAvatar
import com.ux4g.designsystemv1.components.avatar_component.Ux4gStatusAvatarVariant
import com.ux4g.designsystemv1.components.avatar_component.Ux4gAvatarSize

@Composable
fun AvatarShowcaseScreen() {
    Column(modifier = Modifier.padding(16.dp), verticalArrangement = Arrangement.spacedBy(24.dp)) {
        // 1. Basic Avatar
        Ux4gAvatar(
            initials = "AS",
            size = Ux4gAvatarSize.L
        )

        // 2. Profile Avatar with Verified Badge
        Ux4gProfileAvatar(
            initials = "MS",
            size = Ux4gAvatarSize.L,
            variant = Ux4gProfileAvatarVariant.Badge.Verified
        )

        // 3. Avatar Group with Limit
        Ux4gAvatarGroup(
            items = listOf(
                Ux4gAvatarGroupItem(initials = "JD"),
                Ux4gAvatarGroupItem(initials = "AS"),
                Ux4gAvatarGroupItem(initials = "MK"),
                Ux4gAvatarGroupItem(initials = "RJ"),
                Ux4gAvatarGroupItem(initials = "LS")
            ),
            size = Ux4gAvatarSize.M,
            maxLimit = 4,
            collapsed = true
        )

        // 4. Status Avatar
        Ux4gStatusAvatar(
            initials = "RK",
            size = Ux4gAvatarSize.L,
            variant = Ux4gStatusAvatarVariant.Online
        )
    }
}
```

### 1. `Ux4gAvatar` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `modifier` | `Modifier` | Compose layout modifier applied to avatar container. | `Modifier` |
| `size` | `Ux4gAvatarSize` | Dimension token: `XS`, `S`, `M`, `L`, `XL`, `XXL`, `XXXL`. | `Ux4gAvatarSize.M` |
| `shape` | `Shape` | Clip boundary shape (defaults to circle). | `CircleShape` |
| `imageUrl` | `Any?` | Remote image URL, drawable resource ID, or file model. | `null` |
| `initials` | `String?` | 1-2 character initials displayed when image is absent. | `null` |
| `icon` | `Ux4gIcon?` | Fallback vector icon when neither image nor initials are provided. | `Ux4gIcons.Person` |
| `containerColor` | `Color?` | Custom background fill color override. | `null` |
| `contentColor` | `Color?` | Color applied to initials typography text. | `null` |
| `iconColor` | `Color?` | Tint color applied to fallback icon. | `null` |
