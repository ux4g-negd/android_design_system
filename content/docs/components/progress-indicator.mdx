# Progress Indicator Suite

The UX4G Progress Indicator suite provides determinate and animated visual progress representations across three distinct form factors:
1. **Linear Progress Bar (`Ux4gLinearProgressBar`)**: Horizontal track with optional header icons, labels, outside/inside percentage indicators, gradient fills, and smooth animations.
2. **Circular Progress Ring (`Ux4gCircularProgress`)**: 360° ring indicator with auto-scaling center values, metadata labels, sweep gradients, and round/butt caps.
3. **Half-Circle Progress Gauge (`Ux4gHalfCircleProgress`)**: 180° semicircle speedometer gauge with center percentage text, descriptions, and optional 0%–100% boundary scale marks.

Import from `com.ux4g.designsystemv1.components.progress.*`.

<h2><MIcon name="code" /> Kotlin Usage</h2>

```kotlin title="Citizen Onboarding Progress Example"
import androidx.compose.foundation.layout.*
import androidx.compose.runtime.*
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.StrokeCap
import androidx.compose.ui.unit.dp
import com.ux4g.designsystemv1.components.progress.*
import com.ux4g.designsystemv1.foundation.Ux4gColors
import com.ux4g.designsystemv1.foundation.Ux4gIcons

@Composable
fun ProgressShowcaseScreen() {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(28.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        // 1. Linear Progress with Header Label
        Ux4gLinearProgressBar(
            value = 0.75f,
            icon = Ux4gIcons.Info,
            label = "Document Upload Progress",
            hint = "3 of 4 completed",
            showPercentage = true,
            labelPosition = Ux4gProgressLabelPosition.Outside,
            height = 10.dp
        )

        // 2. Circular Ring with Center Content
        Ux4gCircularProgress(
            value = 0.85f,
            size = Ux4gCircularProgressSize.XXL,
            centerValueText = "85%",
            centerDescription = "Verified",
            label = "KYC Verification",
            description = "Aadhaar & PAN matched"
        )

        // 3. Half-Circle Gauge with Scale
        Ux4gHalfCircleProgress(
            value = 0.65f,
            size = Ux4gHalfCircleProgressSize.L,
            valueText = "65%",
            description = "Application Health Score",
            showScale = true,
            strokeCap = StrokeCap.Round,
            progressColor = Ux4gColors.primary
        )
    }
}
```

### 1. `Ux4gLinearProgressBar` Props

| Prop | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| `value` <span className="text-red-500 font-bold">*</span> | `Float` | Determinate progress value between `0.0f` and `1.0f`. | — |
| `modifier` | `Modifier` | Compose layout modifier applied to outer container. | `Modifier` |
| `label` | `String?` | Header title label displayed above-left of the bar. | `null` |
| `hint` | `String?` | Supporting caption text displayed above-right. | `null` |
| `icon` | `Ux4gIcon?` | Optional circular leading icon placed left of label. | `null` |
| `iconColor` | `Color?` | Icon tint color. | `Ux4gColors.primary` |
| `iconBackgroundColor` | `Color?` | Circular background color behind leading icon. | `Ux4gColors.primary (12% opacity)` |
| `height` | `Dp` | Vertical thickness / height of the progress track. | `8.dp` |
| `shape` | `Ux4gProgressShape` | Corner style: `Rounded` (pill shape) or `Sharp` (square ends). | `Ux4gProgressShape.Rounded` |
| `customBorderRadius` | `Dp?` | Explicit corner radius override. | `null` |
| `color` | `Color?` | Solid progress fill color. | `Ux4gColors.primary` |
| `gradientColors` | `List<Color>?` | Two or more colors for horizontal gradient progress fill. | `null` |
| `trackColor` | `Color?` | Background rail track color. | `Ux4gColors.neutral900 (12% opacity)` |
| `showPercentage` | `Boolean` | Whether to render the formatted percentage text. | `false` |
| `labelPosition` | `Ux4gProgressLabelPosition` | Position of percentage label: `Outside` (top-right) or `Inside` (within bar). | `Ux4gProgressLabelPosition.Outside` |
| `insideLabelStyle` | `TextStyle?` | Text style for percentage text rendered inside the bar. | `null` |
