# Color Tokens

The UX4G Color System provides comprehensive, high-contrast, accessible color tokens engineered specifically for citizen services, public governance apps, and enterprise mobile workflows in Android Jetpack Compose.

All primitive tokens, alpha variants, and semantic theme colors are defined in `com.ux4g.designsystemv1.foundation.Ux4gColors` and `com.ux4g.designsystemv1.foundation.Ux4gThemeColors`.
