# Title Tokens

`Ux4gTheme.typography.t*`

Title tokens are medium-emphasis typography styles used in list item headlines, card headers, and top navigation bar titles.

## Jetpack Compose Usage

```kotlin title="Title Usage"
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import com.ux4g.designsystemv1.theme.Ux4gTheme

@Composable
fun CardHeadline() {
    Text(
        text = "Certificate Application Status",
        style = Ux4gTheme.typography.tL_strong,
        color = Ux4gTheme.colorScheme.onSurface
    )
}
```
