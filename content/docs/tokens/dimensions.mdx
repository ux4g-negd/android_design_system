# Dimensions & Spacing Tokens

The UX4G Dimension System provides strict mathematical scaling tokens for spacing, corner radius, and border widths to maintain consistent visual rhythm across Android applications.

All tokens are defined in `com.ux4g.designsystemv1.foundation.Ux4gSpace`, `com.ux4g.designsystemv1.foundation.Ux4gRadius`, and `com.ux4g.designsystemv1.foundation.Ux4gBorderWidth`.

## 4. Kotlin Jetpack Compose Usage

```kotlin title="Compose Usage"
import androidx.compose.foundation.background
import androidx.compose.foundation.border
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.padding
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.ui.Modifier
import androidx.compose.ui.draw.clip
import com.ux4g.designsystemv1.foundation.Ux4gBorderWidth
import com.ux4g.designsystemv1.foundation.Ux4gColors
import com.ux4g.designsystemv1.foundation.Ux4gRadius
import com.ux4g.designsystemv1.foundation.Ux4gSpace

Box(
    modifier = Modifier
        .padding(Ux4gSpace.Space16)
        .clip(RoundedCornerShape(Ux4gRadius.Radius12))
        .border(
            width = Ux4gBorderWidth.Thin,
            color = Ux4gColors.neutral300,
            shape = RoundedCornerShape(Ux4gRadius.Radius12)
        )
        .background(Ux4gColors.white)
) {
    // Card content
}
```
