# Declaration Before Submission

A formal legal affirmation pattern required prior to the final submission of government citizen service requests, certificate applications, or welfare benefit petitions.

To protect against inadvertent or careless submission of incorrect information, the pattern requires citizens to read the full text of the solemn declaration before the agreement checkbox is unlocked. It pairs this with a statutory warning citing **Section 193 of the Indian Penal Code (IPC)** regarding penalties for furnishing false statements, followed by the primary application submission trigger.
