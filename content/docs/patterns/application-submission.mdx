# Application Submission Patterns

Complex multi-step citizen services (such as applying for Caste Certificate, Driving License, or Scholarship) follow a standardized UX4G flow.

---

<h2><MIcon name="assignment" /> Recommended Journey Stages</h2>

1. **Eligibility Check Wizard**: Preliminary questions to confirm applicant meets criteria.
2. **Form Entry & Validation**: Structured fields with live validation error summaries.
3. **Document Scan & Upload**: Verification proofs with progress indicators.
4. **Declaration & Consent**: Official legal undertaking before sign-off.
5. **Submission Acknowledgement**: Reference number badge, downloadable receipt, and SMS confirmation.

---

<h2><MIcon name="code" /> Sample Acknowledgement Screen</h2>

```kotlin
@Composable
fun SubmissionReceiptScreen(
    applicationId: String = "APP-2026-928374",
    serviceName: String = "Income Certificate"
) {
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(Ux4gSpace.space4),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.spacedBy(Ux4gSpace.space4)
    ) {
        Ux4gBadge(text = "APPLICATION SUBMITTED", variant = Ux4gBadgeVariant.Success)
        
        Text(text = "Application #$applicationId", style = Ux4gTheme.typography.h2)
        Text(text = "Your application for $serviceName has been queued for verification.")

        Ux4gButton(
            text = "Download Acknowledgement Slip (PDF)",
            onClick = { /* Generate slip */ },
            variant = Ux4gButtonVariant.Primary
        )

        Ux4gButton(
            text = "Go to Citizen Dashboard",
            onClick = { /* Navigate */ },
            variant = Ux4gButtonVariant.Outline
        )
    }
}
```
