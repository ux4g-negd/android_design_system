# Notification

A comprehensive notification management pattern for citizen mobile applications. The notification center organizes system alerts, application updates, reminders, and action requests into clear chronological sections (*"Today"*, *"Yesterday"*, *"Earlier this week"*). It features distinct color-coded category indicators, direct action triggers (*"Upload now"*), bulk read management (*"Mark as read"*), and a dedicated empty state when no alerts require attention.

### 2. Notification Types Breakdown

Classification reference demonstrating the four standard UX4G notification types with standardized category color codes:
- **Action required**: High-priority alert requiring immediate citizen submission or document upload (Red indicator).
- **Status Update**: Informational transition representing application processing states (Purple indicator).
- **Reminder**: Time-sensitive notice for impending expirations or draft deadlines (Amber indicator).
- **Info**: General government advisory and confirmation messages (Cyan indicator).
