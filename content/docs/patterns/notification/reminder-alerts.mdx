# Reminder Alerts

A progressive notification and advisory pattern for citizen applications facing time-sensitive deadlines, draft expirations, certificate renewals, and scheduled in-person appointments. The pattern uses the official `Ux4gToast` component to deliver contextual floating alerts with standardized UX4G severity categories—transitioning from non-intrusive early guidance (*30 days before*) to actionable warnings (*5 days before*), critical deletion alerts (*2 days before*), expiration notices (*On expiry day*), and immediate appointment reminders (*1 hour before*).

Each alert leverages `Ux4gToast` with its built-in category icon, explicit title, informative guidance text, contextual action button, and dismissible close control.
