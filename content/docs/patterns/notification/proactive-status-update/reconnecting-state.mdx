# Reconnecting State

A network-resilient status pattern for live citizen tracking screens. When the client application detects a temporary socket disconnection or network drop while listening for server-driven updates, the status pill dynamically transitions to an amber **Reconnecting** badge (`Ux4gTag` in Warning tonal style). The view preserves the current milestone state and avoids disruptive error modals while attempting automatic background reconnection with exponential backoff.
