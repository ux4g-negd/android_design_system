# Manual Refresh Prompt

A persistent status advisory pattern utilized when real-time event streaming is unavailable, disabled by policy, or paused due to device battery-saver constraints. Instead of leaving citizens uncertain about milestone progress, a persistent informational banner (`Ux4gToast`) informs them: *"Tap refresh to see the latest status. Your view will not change automatically."*
