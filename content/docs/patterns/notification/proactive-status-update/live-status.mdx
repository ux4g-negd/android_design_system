# Live Status

A proactive status tracking pattern for citizen portals connected to a real-time event stream (such as WebSocket or Server-Sent Events). When an application is receiving live server updates, the top status summary displays an active **Live** indicator tag (`Ux4gTag` in Success tonal style). The view dynamically reflects stage transitions along the **Application journey** without requiring manual page reloads or intrusive popups.
