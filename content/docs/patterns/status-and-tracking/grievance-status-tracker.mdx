# Grievance Status Tracker

A specialized public grievance monitoring pattern that provides citizens with real-time visibility into the investigation, review, escalation, and resolution of administrative complaints filed across central, state, and local portals (such as CPGRAMS or State Public Grievance Portals).

The pattern models the complete grievance resolution lifecycle through 6 distinct administrative states:
- **In Progress (Standard)**: Initial intake state displaying grievance metadata, subject category, and service-level agreement (SLA) countdown.
- **In Progress (2nd Variant)**: Active officer scrutiny state where preliminary examination is underway.
- **Assigned**: Transparent assignment card highlighting the designated Grievance Redressal Officer (GRO), department, and official contact channel.
- **Escalated**: Multi-tier escalation path outlining Level 1 (District GRO), Level 2 (State Appellate Authority), and Level 3 (CPGRAMS National Portal) with active level markers.
- **Resolved**: Positive resolution confirmation with citizen satisfaction feedback capture ("Yes, satisfied" / "No, reopen") within the statutory 30-day review window.
- **Reopened**: Seamless dissatisfaction recourse permitting citizens to specify non-satisfaction reasons and submit additional evidence for re-examination.

@Composable

    cardBg: Color,
    cardBorder: Color,
    textPrimary: Color,
    textSubtle: Color
) {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .clip(RoundedCornerShape(10.dp))
            .background(cardBg)
            .border(1.dp, cardBorder, RoundedCornerShape(10.dp))
            .padding(14.dp)
    ) {
        Text(
            text = "Grievance journey",
            style = TextStyle(fontSize = 15.sp, fontWeight = FontWeight.Bold, color = textPrimary)
        )
        Text(
            text = "Every update from lodging to resolution",
            style = TextStyle(fontSize = 12.sp, color = textSubtle)
        )

        Spacer(modifier = Modifier.height(16.dp))

        val isResolved = status == GrievanceStatus.Resolved
        val isEscalated = status == GrievanceStatus.Escalated || isResolved
        val isUnderReview = status == GrievanceStatus.Assigned || isEscalated

        val steps = listOf(
            Ux4gJourneyStep(
                state = Ux4gJourneyStepState.Completed,
                date = "02 Apr 2026",
                title = "Grievance lodged"
            ),
            Ux4gJourneyStep(
                state = if (status == GrievanceStatus.InProgressVariant2) Ux4gJourneyStepState.Current else Ux4gJourneyStepState.Completed,
                date = "05 Apr 2026",
                title = "Assigned to grievance officer"
            ),
            Ux4gJourneyStep(
                state = when {
                    status == GrievanceStatus.InProgressVariant2 -> Ux4gJourneyStepState.Upcoming
