# Password reset successfully

A completion pattern confirming successful account password recovery. The screen provides positive visual reassurance via a concentric green success checkmark badge, a prominent heading (*"Password reset successfully"*), supportive guidance text (*"Sign in with your new password to continue access to government services."*), a primary **Sign in** action button, and a pinned Digital India brand footer.
