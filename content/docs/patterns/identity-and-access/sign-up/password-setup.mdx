# Password setup

A secure password creation pattern for citizen sign-up and registration flows. The screen features a branded government app header, a primary Password input with visibility toggle, a Confirm password input for matching verification, a primary **Create account** action button, and a pinned Digital India brand footer.

Standard full-screen password creation flow with secure masked inputs, eye visibility toggles, and account completion action.
