# Aadhaar account locked

A high-security lockout screen presented when a citizen exhausts all permissible authentication attempts through the Aadhaar gate. The screen features a prominent centered lock indicator, clear notification of temporary suspension (*"Your Aadhaar authentication has been suspended due to too many failed attempts."*), an automated unlock countdown advisory card (*"Try again in 23:45:00"*), an outlined **Contact UIDAI Support** action, and a pinned Digital India brand footer.
