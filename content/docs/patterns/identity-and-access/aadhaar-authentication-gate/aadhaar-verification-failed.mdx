# Aadhaar verification failed

An error fallback state pattern presented when an Aadhaar authentication attempt fails (such as an incorrect OTP or non-matching facial biometric). The screen features a prominent centered error badge, clear notification of the remaining attempts before temporary account lockout, an inline contextual alert box with attempt status tracking (*"Attempt 1 of 2"*), dual action controls allowing citizens to either **Try Again** or **Try Different Method**, and a pinned Digital India brand footer.
