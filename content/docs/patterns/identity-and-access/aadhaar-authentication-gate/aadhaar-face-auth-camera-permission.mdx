# Aadhaar Face Auth -- camera permission

A security authorization pattern preceding biometric face capture for Aadhaar identity authentication. The screen informs citizens about the necessity of device camera access (*"Allow camera access to capture your face for Aadhaar biometric verification."*), provides local processing privacy reassurance via an informative callout box (*"Camera Access Required"* · *"Your face scan data is processed locally and never stored on our servers."*), paired **Cancel** and **Allow Camera** actions, and a pinned Digital India brand footer.
