# Aadhaar OTP - enter code

A secure Aadhaar verification screen where citizens input the 6-digit one-time password dispatched to their Aadhaar-linked mobile number. The pattern features a branded government header, back navigation button, explicit Aadhaar dispatch messaging (*"A 6-digit OTP has been sent to the mobile number linked to your Aadhaar."*), 6 clean `Ux4gOtpInput` digit boxes, inline countdown resend caption (*"Didn't receive OTP? Resend in 00:17"*), action controls (**Back** and **Verify OTP**), and a pinned Digital India brand footer.
