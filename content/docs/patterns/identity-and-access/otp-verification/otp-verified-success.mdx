# OTP verified - success

A clear confirmation screen shown immediately after a citizen enters a correct one-time password (OTP). The screen features a prominent green concentric check badge, bold confirmation heading (*"Verified!"*), status description (*"Redirecting you to your dashboard..."*), 6 filled `Ux4gOtpInput` digit boxes tinted green via `Ux4gOtpInputStatus.Success` with an integrated *"Verification successful"* caption, and a pinned Digital India brand footer.
