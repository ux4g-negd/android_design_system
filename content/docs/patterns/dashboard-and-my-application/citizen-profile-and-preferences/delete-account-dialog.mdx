# Delete Account Dialog

A critical destructive action confirmation modal pattern safeguarding citizens against unintended account deletion and permanent data loss across government service registries.

The dialog appears centered over a focus-trapping background scrim. It enforces clear decision hierarchy with an unambiguous title (*"Delete your account?"*), statutory policy transparency (highlighting the **30-day grace period** to restore records prior to irreversible deletion), a prominent high-contrast destructive confirmation trigger (`Ux4gButton` with danger styling), and a full-width **Cancel** action allowing citizens to safely abort the operation.

/**

    onCancel: () -> Unit = {}

    ) {
        // Modal Container Card
        Box(
            modifier = Modifier
                .fillMaxWidth()

                .background(cardBg)

                .padding(horizontal = 16.dp, vertical = 24.dp)

                horizontalAlignment = Alignment.CenterHorizontally
            ) {
                // Header Title

                    text = "Delete your account?",
                    style = TextStyle(
                        fontSize = 18.sp,
                        fontWeight = FontWeight.Bold,
                        color = textPrimary

                    textAlign = TextAlign.Center
                )

                    text = "This permanently deletes your account and all associated data. You will have a 30-day grace period to restore it — after that, deletion is final and cannot be undone.",

                        fontSize = 14.sp,

                    textAlign = TextAlign.Center

                    text = "Delete account",

                    variant = Ux4gButtonVariant.Primary,

                    modifier = Modifier.fillMaxWidth()

                    text = "Cancel",

                    size = Ux4gButtonSize.Default,

                )
            }
        }
