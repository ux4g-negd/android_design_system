# No Applications

An onboarding and zero-state dashboard pattern presented to citizens who have not yet initiated or submitted any public service applications.

Rather than presenting an unhelpful blank screen, this pattern combines a welcoming citizen greeting, a high-clarity empty state illustration and prompt (*"No active applications"*), a primary call-to-action button (*"Start application"*), and curated access cards for high-frequency civic services (*Caste Certificate*, *Domicile Certificate*, *Income Certificate*) to accelerate citizen discovery.

/**
