# Application Submitted

A definitive confirmation and receipt pattern displayed upon the successful submission of citizen service petitions, welfare scheme forms, or statutory certificate requests.

The screen provides unambiguous closure to the submission journey by issuing an official application reference ID with one-tap copy functionality, displaying an audit timeline of expected downstream department actions (*"What happens next"*), confirming delivery of automated dispatch alerts via SMS and email, and offering an immediate PDF acknowledgement slip download.
