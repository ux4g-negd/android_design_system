# Could Not Submit

An error handling and submission recovery pattern presented when a citizen's petition, scheme registration, or service application fails to reach the government server due to upstream network drops, server timeouts, or transaction processing exceptions.

Rather than causing distress or data loss, this pattern assures the citizen that their completed inputs and attached documents are securely saved as a draft. Prominent visual failure status, a transparent multi-step progress audit indicating where the process was interrupted, and clear primary recovery options (*"Retry submission"*, *"Save draft"*, and *"Contact support"*) empower citizens to recover smoothly without repeating tedious form entries.
