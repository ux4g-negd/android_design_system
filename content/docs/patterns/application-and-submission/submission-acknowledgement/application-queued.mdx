# Application Queued

An offline-resilient submission acknowledgement pattern displayed when a citizen attempts to finalize their petition, scheme registration, or service request in an environment with unstable, degraded, or absent internet connectivity.

Rather than presenting an abrupt failure or blocking citizen progress, this pattern offers reassurance by affirming that all submitted inputs, attachments, and declarations have been securely cached locally. An informative banner, persistent hourglass affirmation, and prospective audit timeline inform the citizen of automatic background transmission upon reconnection, while offering explicit fallback actions to retry immediately or save safely as a draft.
