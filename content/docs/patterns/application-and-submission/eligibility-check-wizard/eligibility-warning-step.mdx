# Eligibility Warning Step

A conditional outcome pattern presented when an automated assessment cannot definitively resolve all statutory rules, informing the citizen that their application qualifies for manual administrative verification.

This state manages expectations by acknowledging that while most parameters are verified, certain criteria (such as *Income within eligible range*) require discretionary review by an authorized case officer. An orange warning indicator and reassurance copy (*"You May Be Eligible"*) prevent premature abandonment while clarifying that human verification will occur during subsequent processing. A prominent action button (*"Proceed to Apply"*) allows citizens to continue their formal submission without barrier.

                    lineHeight = 20.sp

                thickness = 1.dp,

            )

            Spacer(modifier = Modifier.height(20.dp))

                modifier = Modifier.fillMaxWidth(),
                horizontalArrangement = Arrangement.Start
            ) {
                Text(

                modifier = Modifier.fillMaxWidth()
            ) {
                criteriaList.forEach { criteria ->
                    Row(
                        modifier = Modifier.fillMaxWidth(),

                                    imageVector = Icons.Default.Check,
