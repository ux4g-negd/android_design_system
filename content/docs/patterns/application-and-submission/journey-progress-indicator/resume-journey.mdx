# Resume Journey

An intake continuity pattern designed for citizens returning to an incomplete multi-step petition, restoring their previous workflow state while providing clear orientation and verification cues.

When a citizen resumes an application from a saved draft or previous authenticated session, the pattern positions them immediately at the target milestone (e.g. *Step 3: Documents*) with the horizontal stepper accurately reflected. A prominent contextual advisory banner (*"Resuming from Step 3 — review before continuing."*) explains the restoration context, and previously captured values (such as *Full name* and *PAN number*) are pre-filled so citizens can review, modify, and confirm before proceeding.
