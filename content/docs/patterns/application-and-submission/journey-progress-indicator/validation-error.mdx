# Validation Error

A comprehensive error notification and recovery pattern that surfaces validation failures simultaneously at the global journey level, the milestone stepper, and the specific offending form input.

When an application submission contains missing or malformed inputs, the pattern avoids generic blockers. Instead, it provides three synchronized tiers of visual feedback: the milestone stepper marks the affected stage with an explicit error indicator (`isError = true`), a top-level alert banner summarizes the exact failure count (*"Documents — 1 error found. Tap to jump."*), and the individual input field (e.g. *PAN number*) renders with an error border and contextual helper instructions.
