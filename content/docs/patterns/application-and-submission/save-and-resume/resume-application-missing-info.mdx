# Resume Application Missing Info

An intelligent application resumption pattern that alerts citizens when previously saved sections have missing details, invalid proofs, or updated requirements.

Rather than forcing citizens to navigate through completed sections, the system diagnoses saved application state and flags discrepancies (e.g. *"1 required document missing"*). Returning citizens are provided targeted routing actions: either jump directly to **Go to incomplete section** to resolve outstanding fields or choose **Continue from beginning** for an end-to-end review.

                                        color = if (isDark) Ux4gColors.Neutral700 else Color(0xFFE5E7EB),
                                        shape = CircleShape
