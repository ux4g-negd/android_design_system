# Auto-Save Form

An automated form state persistence pattern that continuously saves citizen inputs in the background without requiring manual "Save Draft" interventions.

As citizens enter personal details, upload proofs, or fill questionnaire fields, an asynchronous auto-save engine securely commits draft changes to the server. An unobtrusive status banner (*"Saved 3:14 PM"*) reassures users that their inputs are protected against power loss, app closure, or accidental browser refresh, coupled with a horizontal step pipeline reflecting active section progression.
