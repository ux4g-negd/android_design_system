# Government form with errors

An intake pattern demonstrating field-level inline error validation within an active citizen application workflow, contrasting locked trusted data with dynamic input validation.

The screen features an active multi-stage stepper (`Ux4gStepper`), auto-save affirmation banner (`Ux4gStatusBanner`), locked trusted records pre-filled from Aadhaar (full name, verified mobile, and Aadhaar number), an invalid email address highlighted with error styling (`Ux4gInputFieldStatus.Error`) and descriptive error caption (*"Enter a valid email."*), state dropdown selection, marital status radio group, optional application narrative textarea, annual income slider, and statutory consent declarations.
