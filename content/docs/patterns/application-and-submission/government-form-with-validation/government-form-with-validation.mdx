# Government form with validation

A production-grade government service intake form engineered for complex citizen applications requiring multi-stage progression, Aadhaar pre-fill verification, granular state selection, conditional declarations, and real-time auto-saving feedback.

The pattern anchors user orientation via a 4-stage horizontal stepper (`Ux4gStepper`) marking the active stage (*Personal*), an affirmative auto-save status pill (`Ux4gStatusBanner`), locked trusted identity records, responsive multi-type inputs (text fields, dropdown selection, marital status radio group, optional narrative textarea, and income slider), statutory verification checkboxes, and dual primary/secondary action triggers.
