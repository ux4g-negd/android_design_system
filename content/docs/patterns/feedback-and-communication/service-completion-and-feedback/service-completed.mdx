# Service Completed

A service fulfillment and milestone completion pattern that confirms the successful issuance and download of a citizen credential (such as an Income Certificate, Caste Certificate, or Land Record).

Rather than leaving citizens uncertain about where their generated document was saved, this pattern confirms download success, displays the file name and size metadata, provides an immediate inline preview link (*"View"*), and offers digital preservation alternatives through official government repositories (*"Save to DigiLocker"*).

The pattern is available in two structural configurations:
1. **Default Style**: Clean, direct full-screen layout anchored by the official government portal header, ghost back navigation, download confirmation banner, file metadata chip, action buttons, and Digital India branding.
2. **Card Style**: An elevated card container situated on a soft tinted purple background (`Ux4gColors.primary100` / `0xFFF2EFFF` in light mode, `primary800` in dark mode) with contained action buttons and centered footer attribution.
