# All Scheduled Languages

A constitutional citizen accessibility pattern providing comprehensive localization support across all 22 official languages recognized in the Eighth Schedule to the Constitution of India, plus English.

The **All Scheduled Languages** pattern provides a unified, accessible selection interface featuring native scripts alongside English phonetic subtitles (*English / United States*, *हिंदी / Hindi*, *मराठी / Marathi*, *தமிழ் / Tamil*, *తెలుగు / Telugu*, *বাংলা / Bengali*, *ગુજરાતી / Gujarati*, *ಕನ್ನಡ / Kannada*, *മലയാളം / Malayalam*, *ଓଡ଼ିଆ / Odia*, *ਪੰਜਾਬੀ / Punjabi*, *অসমীয়া / Assamese*, *संस्कृतम् / Sanskrit*, *اردو / Urdu*, *नेपाली / Nepali*, *मैथिली / Maithili*, *संथाली / Santali*, *डोगरी / Dogri*, *कोंकणी / Konkani*, *बोडो / Bodo*, *सिन्धी / Sindhi*, *कश्मीरी / Kashmiri*, *मणिपुरी / Manipuri*). It features an interactive language trigger and an integrated scrollable selection list with real-time feedback.

The pattern is available in two structural configurations:
1. **Default Style**: Clean full-screen presentation on a neutral canvas featuring the official government portal header, language trigger, expanded bilingual selection panel, and Digital India branding.
2. **Card Style**: An elevated card presentation situated on a soft lavender canvas (`0xFFE2DCFF` / `Ux4gColors.primary100` in light mode, `primary800` in dark mode) enclosing the full scheduled language list within a rounded container.

            elevation = 2.dp

            modifier = Modifier
                .weight(1f)
                .fillMaxWidth()
                .verticalScroll(scrollState)

                text = "All scheduled languages",

                    fontWeight = FontWeight.Bold,
