# Inline Language Toggle

An in-context multilingual form pattern that empowers citizens to switch their active language directly on transactional pages without losing previously entered form data.

Unlike dedicated full-screen configuration pages, the **Inline Language Toggle** embeds language options as a horizontally scrollable sequence of interactive choice chips (`Ux4gChoiceChip`) directly above citizen data entry fields. When a citizen switches language (e.g., from *English* to *हिन्दी*, *தமிழ்*, *తెలుగు*, or *मराठी*), form field labels and input hints update instantaneously in the selected script while preserving user-entered values (*Ramesh Kumar*, *Suresh Kumar*, *2,40,000*).

The pattern is available in two structural configurations:
1. **Default Style**: Full-screen transactional form layout on a clean neutral white canvas featuring the national portal header, inline chip group, localized field labels with edit controls, and Digital India footer attribution.
2. **Card Style**: Elevated card presentation situated on a soft lavender canvas (`0xFFE2DCFF` / `Ux4gColors.primary100` in light mode, `primary800` in dark mode) enclosing the localized form elements within a rounded container.

fun InlineLanguageToggleScreen(

        Ux4gAppHeader(
            title = "",

            leadingSpacing = 8.dp,
            verticalPadding = 16.dp,
            elevation = 2.dp
        )

        // Scrollable Transactional Form Body
        Column(
            modifier = Modifier
                .weight(1f)
                .fillMaxWidth()
                .verticalScroll(scrollState)
                .padding(horizontal = 16.dp, vertical = 20.dp)
        ) {
            // Screen Title
            Text(
                text = "Apply for Income Certificate",
                style = TextStyle(
                    fontSize = 22.sp,
                    fontWeight = FontWeight.Bold,
                    color = colors.titleColor
                )
            )

            Spacer(modifier = Modifier.height(8.dp))

            // Subtitle / Instruction
            Text(
                text = "Use the language switcher to change the form language. Your entered details will stay saved.",
                style = TextStyle(
                    fontSize = 14.sp,
                    color = colors.subtitleColor,
                    lineHeight = 20.sp
                )
            )

            Spacer(modifier = Modifier.height(20.dp))

            // Horizontally Scrollable Language Choice Chips
            Row(
                modifier = Modifier
                    .fillMaxWidth()
                    .horizontalScroll(chipScrollState),
                horizontalArrangement = Arrangement.spacedBy(8.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                availableLanguages.forEachIndexed { index, lang ->
                    Ux4gChoiceChip(
                        text = lang.name,
                        selected = selectedIndex == index,
                        onClick = {
                            selectedIndex = index
                            onLanguageChange(lang)
                        },
                        size = Ux4gChoiceChipSize.Default
                    )
                }

                // Overflow "+3 more" chip
                Ux4gChoiceChip(
                    text = "+3 more",
                    selected = false,
                    onClick = { /* Open full language selector modal */ },
                    size = Ux4gChoiceChipSize.Default
                )
            }

            Spacer(modifier = Modifier.height(24.dp))

            // Form Field 1: Applicant Name
            FormFieldItem(
                label = currentLang.applicantLabel,
                value = "Ramesh Kumar",

                .fillMaxWidth()
                .clip(RoundedCornerShape(10.dp))

                .border(
                    width = 1.dp,
                    color = colors.fieldBorder,
                    shape = RoundedCornerShape(10.dp)
                )
                .clickable { onEdit() }
                .padding(horizontal = 14.dp, vertical = 13.dp),
            verticalAlignment = Alignment.CenterVertically,
            horizontalArrangement = Arrangement.SpaceBetween
        ) {
            Text(
                text = value,
                style = TextStyle(
                    fontSize = 14.sp,
                    fontWeight = FontWeight.Medium,
                    color = colors.fieldValueColor
                ),
                modifier = Modifier.weight(1f)
            )

            Icon(
                imageVector = Icons.Outlined.Edit,
                contentDescription = "Edit field",
                tint = colors.fieldIconColor,
                modifier = Modifier.size(18.dp)
            )
        }
    }
}
