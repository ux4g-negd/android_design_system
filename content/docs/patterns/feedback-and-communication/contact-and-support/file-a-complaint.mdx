# File a Complaint

An official grievance submission pattern that allows citizens to register formal complaints and service disputes directly with administrative authorities.

The pattern captures structured incident metadata including a concise subject header (`Ux4gInputField`), grievance classification taxonomy (`Ux4gSelectionDropdown`), and an expansive multi-line narrative description (`Ux4gTextArea`) detailing the timeline, expectations, and nature of the bottleneck.

The pattern is available in two structural configurations:
1. **Default Style**: Clean, direct layout situated on a neutral white canvas featuring the official government portal header, structured grievance form, action buttons, and Digital India branding.
2. **Card Style**: An elevated card variant situated on a soft lavender canvas (`0xFFE2DCFF` / `Ux4gColors.primary100` in light mode, `primary800` in dark mode) with enclosed card container and footer attribution.
