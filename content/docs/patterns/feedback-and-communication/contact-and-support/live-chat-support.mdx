# Live Chat Support

A real-time citizen assistance pattern that connects citizens directly with public service support representatives to resolve immediate blockers during application submission or benefit claims.

The pattern displays real-time agent availability and queue metrics (*"Queue agent available · Estimated wait time: 1-2 mins"*) inside a prominent status card. Citizens can initiate an immediate interactive chat session with a single tap or choose an asynchronous fallback channel (*"Email support instead"*).

The pattern is available in two structural configurations:
1. **Default Style**: Clean, direct layout situated on a neutral white canvas featuring the official government portal header, live queue status indicator, action buttons, and Digital India branding.
2. **Card Style**: An elevated card variant situated on a soft lavender canvas (`0xFFE2DCFF` / `Ux4gColors.primary100` in light mode, `primary800` in dark mode) with enclosed card container and footer attribution.
