# Inline Feedback Error

An inline validation and status communication pattern that provides citizens with immediate, contextual error guidance when entered data fails formatting or syntax requirements (such as providing an incomplete mobile number for OTP delivery or biometric authentication).

Rather than forcing citizens through a full round-trip submission before flagging mistakes, this pattern identifies syntax discrepancies immediately at the input level—highlighting the input border in accessible red (`Ux4gColors.danger500`), displaying an alert icon, and providing explicit remediation instructions (*"Enter a valid 10-digit mobile number"*).

The pattern is available in two structural configurations:
1. **Default Style**: Clean, full-screen layout anchored by the official government portal header, ghost back navigation, clear instructions, field-level error indicators, and a full-width bottom continuation button.
2. **Card Style**: An elevated card container situated on a soft tinted purple background (`Ux4gColors.primary100` / `0xFFF2EFFF` in light mode, `primary800` in dark mode) with pinned bottom progression controls.
