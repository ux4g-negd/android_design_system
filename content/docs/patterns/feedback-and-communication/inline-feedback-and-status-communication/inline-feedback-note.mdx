# Inline Feedback Note

A reviewer-to-citizen feedback pattern that displays official remarks, discrepancy explanations, and corrective instructions directly inside the citizen application journey (such as a Revenue Inspector requesting a clearer scan of an income certificate due to glare).

Instead of sending generic rejection emails or cryptic status codes, this pattern presents human-authored officer observations within a prominent warning alert container. The note articulates the exact issue, provides clear remedial actions, and states precise submission timelines (*"Resubmit within 5 working days to avoid delay"*), helping citizens resolve application snags promptly without re-starting the process from scratch.

The pattern is available in two structural configurations:
1. **Default Style**: Clean, direct form layout anchored by the official government portal header, back navigation, headline guidance, reviewing officer note container, and a full-width bottom progression button.
2. **Card Style**: An elevated card container situated on a soft tinted purple background (`Ux4gColors.primary100` / `0xFFF2EFFF` in light mode, `primary800` in dark mode) with pinned bottom progression controls.
