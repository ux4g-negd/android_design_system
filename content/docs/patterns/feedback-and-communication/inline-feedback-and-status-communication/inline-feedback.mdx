# Inline Feedback

An inline validation and status communication pattern that provides citizens with immediate, contextual positive reinforcement during critical data entry (such as income declarations, pension thresholds, or subsidy eligibility checks).

Rather than deferring validation until final form submission, the pattern verifies citizen input syntax in real time (*"Amount format looks correct"* accompanied by an accessible green check indicator). This eliminates anxiety, prevents avoidable submission rejections, and builds confidence in public digital workflows.

The pattern is available in two structural configurations:
1. **Default Style**: Clean, direct form layout anchored by a government header, back navigation, clear fiscal guidance, and a full-width bottom progression button.
2. **Card Style**: An elevated card container situated on a soft tinted purple background (`Ux4gColors.primary100` / `primary800`) with pinned bottom progression controls.
